# Detaching a SUBTREE ROOT stashes the whole subtree as a subassembly, and the
# launch that follows carries only what is left.
#
# This used to run --vab-detach 1 on tanker. The hook selected the part by index,
# so the case never proved the part was reachable by picking it. It also sits
# behind the core from the editor's default angle, which is normal for a 3D
# scene -- a player orbits and clicks it, and --ui-focus says so plainly rather
# than picking a neighbour (#311). stager is a straight chain, so dec_1 is a
# subtree root that is pickable from any angle, and the stash arithmetic is the
# same shape: 3 parts go, 4 stay.
#
# The stash itself is asserted, not inferred from the launch count: the toast
# says it went to Subassemblies and how many came with it.
NAME vab-detach-asm
ARGS --vab res/ships/stager.json --width 1920 --height 1080 --timeout 8
ARGS --ui-focus 1500,dec_1
ARGS --sim-mouse 1600,0,CUR,CUR,LMB
ARGS --ui-click 2500,"VAB/Detach subtree"
ARGS --ui-click 4000,"VAB TopBar/LAUNCH"
CHECK re.search(r"\[vab\] select 4 dec_1", out)
CHECK re.search(r"\[vab\] detached dec_1 \(3 parts\)", out)
EXPECT [toast] Detached dec_1 (+2) to Subassemblies
CHECK re.search(r"\[vab\] launched 'stager' \(4 parts\)", out)
FORBID FAILED
FORBID GL_
