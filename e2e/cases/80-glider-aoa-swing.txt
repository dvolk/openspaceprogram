# Glider AoA swing (ship-level silhouette drag): on Duna (thin air, low
# gravity so the glider lifts off), ramp throttle (R), fire (T), then pitch
# the nose over (W) while the ship is still moving. As the nose rotates past
# the velocity vector the wings go from edge-on to broadside, so the ship's
# projected silhouette area -- the drag model's whole point -- must GROW with
# AoA. A fixed side-area approximation can't do this; only the hull silhouette
# does. The fuel tank dominates the hull, so the total swing is modest (~25%),
# but it must be present and attitude-dependent.
#
# The two assertions are paired: (1) the nose actually rotated to a broadside
# attitude (AoA swung well past 0), and (2) the silhouette area grew with it
# (broadside A > edge-on A). Either failing means the attitude-dependent
# silhouette is broken.
NAME glider-aoa-swing
ARGS --body Duna --scenario pad --ship res/ships/glider.json --time-accel 1
ARGS --timeout 10 --drag-log
ARGS --sim-press 1000,2000,R
ARGS --sim-press 1500,3000,T
ARGS --sim-press 5500,2500,W
EXPECT [drag]
CHECK len(drag) >= 2
# The engine fired and the ship moved through the air (drag is live).
CHECK any(d["F"] > 0 and d["rho"] > 0 for d in drag)
# The nose actually rotated (AoA swung well past 0 -> broadside attitude).
CHECK max(abs(d.get("aoa", 0.0)) for d in drag) > 30
# ...and the silhouette area grew with it (broadside > edge-on).
CHECK max(d.get("a", 0.0) for d in drag) > min(d.get("a", 0.0) for d in drag) * 1.05
# The cd FOLLOWS the attitude (the directional-drag SIGN convention): at the
# lowest |AoA| the capsule's sleek nose + edge-on wings keep cd LOW, and at
# the broadside attitude the blunt base + flat-plate wings push cd UP. A
# flipped nose-axis/flow sign would reverse this -- making every cone sleek
# the wrong way -- so this pins that dot(nose, flow) = +1 means nose-in.
CHECK (lambda ds: (ds and max(ds, key=lambda d: abs(d["aoa"]))["cd"] > min(ds, key=lambda d: abs(d["aoa"]))["cd"] * 1.05))([d for d in drag if d.get("aoa") is not None and d.get("cd") is not None])
FORBID GL_
