# BuiltSave's roster rollback, pinned at the only place it can still fire.
# #305's same-system preflight refuses a bad part BEFORE any roster swap
# (case 232), so that path never needs a restore. The swap still happens for
# refusals only a BUILD can see -- deep containment, addSeat, make_part -- and
# those must put the running cast list back or the career becomes a file the
# game wrote and cannot read (case 232's failure mode, one step later).
# This fixture is the 305 deep tree PLUS a shrunk roster (Bram + Cyd). The
# build swaps the roster in, then refuses the containment tree: the destructor
# restores the three kerbals from --kerbals.
NAME deep-tree-rolls-back-roster
ARGS --system res/systems/ksp_system.json --kerbals e2e/fixtures/three_kerbals.json
ARGS --time-accel 1 --timeout 8
ARGS --startship racer,res/ships/racer.json,Kerbin,rot-orbit
ARGS --reload e2e/fixtures/save_solar_deep_tree_roster --reload-at 3000
EXPECT [load] refused e2e/fixtures/save_solar_deep_tree_roster
EXPECT has a broken containment tree
EXPECT [load] roster restored: 3 kerbal(s)
