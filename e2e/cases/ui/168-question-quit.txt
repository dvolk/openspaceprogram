# "Quit game" from the Space Center hub asks first. The shared menu shell
# (drawMenuWindow) draws that button for both menus, so the gate is
# gameRunning() -- the scene stack's own "a game is in charge" -- not the
# scene name: quitting discards everything since the last manual save (no
# autosave, no save-on-quit), which is only true when a game is loaded.
# The affirmative answer is what matters here: the loop must actually stop
# early, so "Timeout reached" is forbidden rather than an exit line asserted.
NAME question-quit
CLAIM Quit game from a live game asks first.
KIND invariant
ARGS --ui-click 400,"Title Menu/New Game" --ui-click 1000,"New Game/Start" --timeout 6
ARGS --ui-click 2500,"Game Menu/Quit game"
ARGS --ui-list 3000
ARGS --ui-click 3400,"Question/Quit"
EXPECT [ask] Quit the game?
EXPECT [Quit | Stay]
EXPECT window="Question" label="Quit"
EXPECT [ask] answered 0
FORBID FAILED
FORBID Timeout reached
FORBID error:
