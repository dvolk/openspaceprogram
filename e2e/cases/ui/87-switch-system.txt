# A bare system switch, through the player's only route: the New Game sheet's
# system picker (startNewGame switches first, then newGame). --switch-system
# used to call Game::switchSystem directly; the sheet is the same call, plus the
# mint a player also gets.
# --title-body pins the boot backdrop to Kerbin; after the switch that name is
# gone, so the pin-miss line is the witness that the title re-picked against the
# NEW system -- a switch that left the old backdrop standing would never print
# it (and a bare "[title] backdrop:" would match the boot print).
# The sheet lists system file stems; "solar_system" is res/systems/solar_system.json.
NAME switch-system
CLAIM A New Game system picker switches systems and mints the game.
KIND invariant
ARGS --system res/systems/ksp_system.json --title-body Kerbin --timeout 10
ARGS --ui-click 1500,"Title Menu/New Game"
ARGS --ui-click 2000,"New Game/##newgame_system"
ARGS --ui-click 2500,"##Combo_00/solar_system"
ARGS --ui-click 3000,"New Game/Start"
EXPECT Loaded system 'res/systems/ksp_system.json'
EXPECT [boot] no vessel: title screen
EXPECT [game] switched system -> res/systems/solar_system.json (home Earth,
EXPECT Loaded system 'res/systems/solar_system.json'
EXPECT [title] backdrop pin 'Kerbin' not found; picking randomly
EXPECT [game] new game: Space Center, no ship, paused
