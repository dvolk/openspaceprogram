# #1020: what a player gets when they BUILD the asparagus shape rather than load one somebody
# numbered. asparagus.json (e2e/vehicles/, so it needs Game Debug's dev-vehicles switch) is a
# capsule, a core stage, and three radial boosters chained to each other and into the core by
# fuel links -- placed and never numbered, so every part still carries the default label 1.
#
# With nothing authored, depth is the only signal and it gives the shape the rocket has: the
# three booster cuts sit at one tree depth, so they share the first press, and the core's cut
# sits a press below them. The core engine is not on that lower label: nothing is ever under it,
# so the free-engine rule (#1033) lights it from the pad -- the one ignition fact the part tree
# does supply, and the same answer 1020-a's authored ladder gives by being typed.
#
# The fuel links make this a real asparagus stack to FLY, but they move no number: autoStage
# reads the part tree, not the drain graph, so the ladder is the same with the links deleted.
# Sequencing an un-numbered ring by its feed chain is #1031, not this case.
NAME auto-stage-numbers-a-fresh-asparagus-stack
CLAIM Auto-stage numbers a placed, un-numbered asparagus stack: the booster ring on one press, the core's cut a press below it, and the checker left nothing to say.
KIND invariant
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3200,0,F1
ARGS --ui-click 3700,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4200,0,F1
ARGS --ui-type 4700,"VAB TopBar/##vehfilter",asparagus
ARGS --ui-click 5300,"VAB TopBar/##vabload"
ARGS --ui-click 5900,"asparagus"
ARGS --ui-click 6500,"VAB TopBar/Load"
ARGS --ui-click 7100,"Staging/Auto-stage"
ARGS --stage-dump 7900 --timeout 14
LIMIT 60
EXPECT [vab] loaded asparagus (13 parts)
EXPECT [toast] Auto-staged 12 parts from the stack
EXPECT [autostage] note: 1 engine(s) lit as soon as the stack leaves them free
# The ring is one press: three cuts, one tree depth, nothing authored to separate them.
EXPECT [stagetree] 4 dec_a def=decoupler_radial parent=core_tank stage=3 responds=decoupler
EXPECT [stagetree] 7 dec_b def=decoupler_radial parent=core_tank stage=3 responds=decoupler
EXPECT [stagetree] 10 dec_c def=decoupler_radial parent=core_tank stage=3 responds=decoupler
EXPECT [stagetree] 6 a_eng def=engine parent=a_tank stage=3 responds=engine
# The core stage rides a press below them; its engine does not, because there is nothing under it
# to wait for (#1033).
EXPECT [stagetree] 1 dec_core def=decoupler_r1 parent=pod_1 stage=2 responds=decoupler
EXPECT [stagetree] 3 core_eng def=engine parent=core_tank stage=3 responds=engine
EXPECT [stagetree] 0 pod_1 def=capsule parent=- stage=1 responds=-
EXPECT [stagetree] labels=1..3 presses=2 inert_parts=5/13
FORBID [stagetree] warn:
FORBID error:
FORBID FAILED
