# The hull card's Form row (#1090): the union silhouette bills the ship ONCE, but
# the #945 partition keeps the score by part, and the silhouette cache nodes carry
# that partition so the per-part numbers exist on chart hits too. Right-click the
# pod and the tank of a cruising skiff -- both body parts -- and each card prints
# "Form: <m2> visible  cd <cd>  drag <W>" on the #734 instrument cadence. The
# OSP_SHIP_DUMP audit showed these numbers one flag away (at alpha 0 the pod keeps
# the whole union, visA 0.78 = unionA, and the sheltered tank 0.00); this puts them
# where the player can ask. A body card carries NO surface "Drag power" row -- the
# blocks are disjoint, and that is the player-visible half of the claim.
NAME hull-card-form-row
CLAIM Body part cards print the silhouette credit row at cadence; the upwind capsule reads a real area and cd; no surface rows on body cards.
KIND invariant
ARGS --time-accel 1 --sim-steps 600 --width 1920 --height 1080 --startship skiff_trim,res/ships/skiff_trim.json,Kerbin,flying-cruise
ARGS --ui-focus 2000,skiff_trim/pod
ARGS --sim-mouse 2200,0,CUR,CUR,RMB
# The tank sits behind the pod along the flight line -- that occlusion IS the story
# (the audit at alpha 0 credits the tank 0.00 for exactly this reason) -- so the
# chase camera cannot aim at it: orbit like a player (harness/281's RMB drag) and
# aim again.
ARGS --sim-mouse 2600,800,960,300,RMB
ARGS --sim-mouse 3400,0,960,620,0
ARGS --ui-focus 4200,skiff_trim/tank
ARGS --sim-mouse 4400,0,CUR,CUR,RMB
ARGS --ui-list 6000 6100 6200 6300 6400 6500 6600 6700 6800 6900 7000
EXPECT [uilist] loop=
# One Form row per read per card, and exactly the two body cards print one.
CHECK len([r for r in uilist if r["label"].startswith("Form:")]) == 11 * 2
CHECK len({r["window"] for r in uilist if r["label"].startswith("Form:")}) == 2
# Body cards carry no surface flow/power rows (those blocks gate on lift_area).
CHECK not any(r["label"].startswith("Drag power") for r in uilist)
CHECK not any(r["label"].startswith("AoA:") for r in uilist)
# Cadence (#734): eleven reads 100 ms apart see the PUBLISHED figures, never more
# than a couple of them. The lower bound is deliberately 1 here: unlike the wing
# loads (0.7..39 kW across the trim porpoise in 734), a pod's frontal credit barely
# responds to that oscillation -- 0.78 m2 and 8.9 kW round steady -- so one distinct
# figure is honest physics, not a frozen panel. The UPPER bound is the guard: with
# the hold gone the row repaints from every frame's live figures, and this row
# prints to quarter-watts (945.3 W) on a porpoising hull -- it cannot repaint
# steady, which is how 734 caught the shared-state bug at 11 distinct figures.
CHECK 1 <= len({r["label"] for r in uilist if "Capsule (1m)" in r["window"] and r["label"].startswith("Form:")}) <= 5
# The column holds: fixed-cell figures print the same character count every read.
CHECK len({len(r["label"]) for r in uilist if r["label"].startswith("Form:")}) == 1
# The pod is the upwind-most body of the stack, so every pod read carries a real
# credit -- area >= 0.3 m2 (its own silhouette is ~0.8) and a NUMERIC cd. A sheltered
# part would dash the cd cell; the pod never may.
CHECK all(re.search(r"Form:\s+([0-9.]+) m2 visible  cd \d", r["label"]) and float(re.search(r"Form:\s+([0-9.]+) m2", r["label"]).group(1)) >= 0.3 for r in uilist if "Capsule (1m)" in r["window"] and r["label"].startswith("Form:"))
# Every row parses on both cards: the cd cell is numeric or the four-cell dash,
# and a drag figure follows.
CHECK all(re.search(r"Form:\s+[0-9.]+ m2 visible  cd (   -|\d+\.\d+)  drag .+", r["label"]) for r in uilist if r["label"].startswith("Form:"))
FORBID error:
