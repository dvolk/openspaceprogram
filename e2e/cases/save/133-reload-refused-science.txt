NAME reload-refused-science
CLAIM A refused reload does not clobber the running career's science.
KIND invariant
# A refused reload must not clobber the running career science (issue #133).
# Boot loads a save carrying score 1 / 1 recovered, then a refused reload of a
# score-0 save (a part no longer in the catalog) must leave that science
# untouched -- the fleet rolls back, and so must the career score + log.
# #305/#301: a refusal never moves the clock and never touches science, so
# the confirmation line is what proves it (there is no restore to observe).
SEED e2e/fixtures/save_corrupt saves/20260101_000000-reload/save1
ARGS --load e2e/fixtures/save_science --time-accel 1 --timeout 10
ARGS --sim-press 1500,0,ESCAPE
ARGS --ui-click 2000,"Game Menu/Save/Load"
ARGS --ui-click 3500,"Save/Load/Load##saveload"
EXPECT Loaded game from e2e/fixtures/save_science (active: racer)
EXPECT [load] refused
EXPECT no_such_part_in_the_catalog
EXPECT [load] running game unchanged
EXPECT science score=1 recovered=1
FORBID [load] clock restored
FORBID science reset
FORBID 20260101_000000-reload/save1 (active:
FORBID error:
