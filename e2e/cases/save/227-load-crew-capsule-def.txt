# Case 220's racer def is multi-part, so it trips the SIZE half of the crew-def
# gate and never reaches the TYPE half. A hand-edited save can name a def that is
# exactly one part but not a kerbal -- here a lone capsule. That would mint a
# "person" that is a command pod: no kerbal part, so isSeat() is false for
# anything parked in it, and its crew_capacity would then be read by a capsule
# that is not a capsule. Refuse it by name.
NAME load-crew-capsule-def
CLAIM A one-part non-kerbal def named as crew is refused.
KIND invariant
ARGS --load e2e/fixtures/save_kerbal_capsule_def --timeout 4
EXPECT Load failed: load: kerbal 'kerbal' has def 'e2e/fixtures/one_capsule.json', which is a 'capsule' part, not a kerbal
EXIT 1
LIMIT 60
