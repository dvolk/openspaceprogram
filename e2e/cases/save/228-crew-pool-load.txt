# The pad's cast is part of the save (save.json's crew_pool, format 4): a load
# stands THOSE people back up rather than minting from the roster, so a career
# that spent or recovered people keeps its own crew count. This save flew with
# Ace seated in racer and Bram + Cyd waiting at the pad; the load prints both
# halves. There is no fallback mint: an empty pool is a spent cast, and a load
# that quietly re-stocked it would hide a lost crew.
NAME crew-pool-load
CLAIM A save's pad cast is rebuilt as written, with no fallback mint.
KIND invariant
ARGS --timeout 9
# Reached by the Save/Load sheet, not --load: Game Debug ticks the e2e
# fixture root, the sheet picks the "fixtures" game, the slot filter
# narrows the fixture list to this one row, and row + Load button do
# the rest. Same load_game() either way, so the assertions below are
# unchanged. The PERIOD presses climb
# the warp ladder where --time-accel used to: a sheet
# load starts paused.
ARGS --sim-press 500,0,F1
ARGS --ui-click 1000,"Game Debug/Load e2e fixture saves"
ARGS --sim-press 1500,0,F1
ARGS --ui-click 2000,"Title Menu/Save/Load"
ARGS --ui-click 2500,"fixtures"
ARGS --ui-type 3000,"Save/Load/##filter",save_crew_pool
ARGS --ui-click 3800,"save_crew_pool"
ARGS --ui-click 4000,"Save/Load/Load##saveload"
ARGS --sim-press 4300,0,PERIOD
EXPECT [crew] loaded 'Ace' aboard 'racer'
EXPECT [crew] 2 kerbal(s) standing at 'main_space_port' (from save)
EXPECT Loaded game from e2e/fixtures/save_crew_pool (active: racer)
EXPECT [toast] Loaded fixtures/save_crew_pool
FORBID [load] refused
FORBID Load failed
FORBID error:
FORBID FAILED
LIMIT 60
