# #266's fallback branch: save.json here is save_roster_named with the
# "active_ship" key REMOVED, so the loader has to pick an active vehicle itself.
# The fleet is TWO vessels -- v0 'racer', with Ash seated in its capsule, and v1,
# an uncrewed copy of the same ship also named 'Ash' -- so the candidate rules
# disagree: first in save order gives 'racer', alphabetically first NAME gives
# 'Ash', last built gives 'Ash'. The old fallback was byName.begin(), so the
# FORBID below is exactly what it used to do: park the camera on a ship 300 m
# away and leave the seated kerbal out of reach.
NAME load-no-active-ship
CLAIM A save without active_ship picks a vessel deterministically.
KIND invariant
ARGS --timeout 8
# Reached by the Save/Load sheet, not --load: Game Debug ticks the e2e
# fixture root, the sheet picks the "fixtures" game, the slot filter
# narrows the fixture list to this one row, and row + Load button do
# the rest. Same load_game() either way, so the assertions below are
# unchanged. The PERIOD presses climb
# the warp ladder where --time-accel used to: a sheet
# load starts paused.
ARGS --sim-press 500,0,F1
ARGS --ui-click 1000,"Game Debug/Load e2e fixture saves"
ARGS --sim-press 1500,0,F1
ARGS --ui-click 2000,"Title Menu/Save/Load"
ARGS --ui-click 2500,"fixtures"
ARGS --ui-type 3000,"Save/Load/##filter",save_no_active
ARGS --ui-click 3800,"save_no_active"
ARGS --ui-click 4000,"Save/Load/Load##saveload"
ARGS --sim-press 4300,0,PERIOD
EXPECT [crew] loaded 'Ash' aboard 'racer'
EXPECT Loaded game from e2e/fixtures/save_no_active (active: racer) [v0]
EXPECT [toast] Loaded fixtures/save_no_active
FORBID (active: Ash)
FORBID [load] refused
FORBID error:
FORBID FAILED
LIMIT 60
