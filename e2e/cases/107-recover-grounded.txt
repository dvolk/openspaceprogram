# Recovering a ship that is grounded on its home body: the hub's "Recover
# Vessel" button, which is the only way a player ends a flight successfully.
# ESC pops flight -> hub, and the button sits in the hub's Game Menu.
#
# This is the case that covers the button under the game's OWN rule: recover
# needs the ship grounded on its home body (game.cpp:2137), with no debug flag in
# play. The orbit cases click this same button and pass --recover-anywhere, which
# is a permission rather than a shortcut: it relaxes that one rule and nothing
# else. 116 and 121 start grounded, so they need no flag either, and 108 covers
# the other half of the gate -- grounded on somebody else's body. 265 still uses
# the --recover hook: the game is in the VAB with a question card up, and every
# key answers the card instead of opening the hub.
NAME recover-grounded
ARGS --time-accel 1 --timeout 8 --startship racer,res/ships/racer.json,Kerbin,pad
ARGS --sim-press 1000,0,ESCAPE
ARGS --ui-click 2000,"Game Menu/Recover Vessel"
EXPECT [scene] flight -> spacecenter (push)
EXPECT [recover] t=
EXPECT 'racer' recovered
EXPECT [scene] spacecenter -> spacecenter (enterSpaceCenter)
EXPECT Timeout reached (8.
FORBID FAILED
FORBID GL_
