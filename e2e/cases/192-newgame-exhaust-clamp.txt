# The New Game sheet's difficulty band (0.8-2.0) is narrower than what
# --exhaust-scale and the save loader accept (0.5-5). Opening the sheet after a
# 5.0 boot must clamp the draft into the band: without the clamp the knob parks
# at 2.0 while Start still commits the 5 it was seeded with, so the sheet lies
# about the game it starts.
NAME newgame-exhaust-clamp
ARGS --timeout 8 --exhaust-scale 5 --ui-click 1500,"Title Menu/New Game" --ui-click 2500,"New Game/Start"
EXPECT [game] new game 'game1' (exhaust 2.00x)
FORBID exhaust 5.00x
FORBID GL_
LIMIT 30
