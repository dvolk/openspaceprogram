# Two capsules, both named, and the SECOND one is detached out of the build (a
# lone part is deleted rather than stashed). The plan for the part that left is
# dropped; the plan for the one that stayed must still fly. The ids here are
# longer than std::string's small-buffer on purpose: reading the erased entry
# after vector::erase then showed up as mojibake in the toast instead of a
# plausible part name, and a shorter id hides it.
#
# The detach is the player's route now: --ui-focus names the doomed capsule, the
# game finds a pixel that picks it, click there, then click "Detach subtree".
# --vab-detach 1 selected by index and never checked that a pick lands on part 1;
# the "[vab] select" line says which part the click took.
#
# The aim happens AFTER the two assigns, and that ordering matters: --vab-assign
# opens the seat window, and a click inside it is swallowed -- correct behaviour,
# but it means the pixel the aim picks has to be one the window does not cover.
# The aim's spiral only asks the 3D pick whether a pixel hits the part; it does
# not know about windows. If this case ever stops selecting, check whether the
# seat window now covers the reported pixel.
NAME vab-seat-detached-two
ARGS --vab e2e/fixtures/two_capsules.json --kerbals e2e/fixtures/three_kerbals.json
ARGS --width 1920 --height 1080 --time-accel 1 --timeout 12 --frame-cap 30
ARGS --vab-assign 3000,1,0,Ace --vab-assign 3200,0,0,Bram
ARGS --ui-focus 4000,capsule_r1.5h3_2
ARGS --sim-mouse 4500,0,CUR,CUR,LMB
ARGS --ui-click 5000,"VAB/Detach subtree"
ARGS --vab-launch 7000
EXPECT [vab] assign hook: 'capsule_r1.5h3_2' seat 0 = 'Ace'
EXPECT [vab] assign hook: 'capsule_r1.5h3_1' seat 0 = 'Bram'
EXPECT [vab] select 1 capsule_r1.5h3_2
EXPECT [vab] deleted capsule_r1.5h3_2 (single part, not stashed)
EXPECT [vab] dropped the seat plan for 'capsule_r1.5h3_2' 'Ace' (it left the build)
EXPECT [toast] 1 seat assignment dropped: no such seat in this build
CHECK re.search(r"Crew: 'Bram' aboard '.*' part 0 \(1/3\)", out)
EXPECT [vab] launched 'two capsules' (1 parts)
FORBID Crew: 'Ace'
FORBID Crew: 'Cyd'

FORBID to Subassemblies
FORBID Assertion
FORBID Segmentation
FORBID FAILED
