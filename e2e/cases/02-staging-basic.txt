# Staging: on the pad, the first SPACE fires the stager's decoupler
# (stage 1), dropping the boosters; the second finds no decoupler at stage 2
# (the capsule's stage), so nothing is dropped -- the capsule (which carries
# the crew) is safe because it sits on the root side of the decoupler.
# Verifies the stage-separation path end to end.
# Anchors are the exact strings the staging handler prints.
NAME staging-basic
ARGS --scenario pad --ship res/ships/stager.json --time-accel 1 --timeout 12
ARGS --sim-press 2000,100,SPACE
ARGS --sim-press 6000,100,SPACE
EXPECT Stage: dropped
EXPECT Stage: nothing left to separate
FORBID GL_
FORBID error:
