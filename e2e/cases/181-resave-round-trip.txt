# --save and --load are mutually exclusive, so a save/load round trip took two
# runs plus a committed fixture to compare (#51). --resave writes at --timeout
# ALONGSIDE a --load, so one process loads a save, flies it, and writes it back:
# diff the input tree against tmp/e2e_save_out and a field the writer drops or
# the reader misreads shows up as a diff, instead of as a ship parked at the
# body centre. That is the tool that would have caught the half-parsed-format
# bug at the time it was introduced (kSaveFormat now refuses it -- see 172).
NAME resave-round-trip
SEED e2e/fixtures/save_racer saves/in
ARGS --timeout 4 --time-accel 1
ARGS --load in
ARGS --resave tmp/e2e_save_out
ARGS --orbit-log --orbit-interval 1
EXPECT Load: using saves slot
EXPECT saves/in (active: racer)
EXPECT Saved 2 ship(s) to tmp/e2e_save_out
EXPECT [orbitlog]
FORBID Save failed
FORBID Load failed
FORBID [load] refused
FORBID GL_
FORBID error:
LIMIT 60
