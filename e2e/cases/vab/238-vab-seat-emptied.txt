# The player names a seat, then picks "Empty" for it on purpose. "Nobody in
# this seat" is a CHOICE, not an absence: the launch must not hear "I never
# said anything" and put the pad's FIFO line aboard (issue #287). The pad still
# has all three kerbals standing on it, so auto-fill COULD have crewed the
# capsule -- it must not.
#
# Both choices are dropdown rows now: Seat 1 -> Ace, Seat 1 -> Empty. The hook
# used to print each assignment as evidence of its own work; that is gone, and
# FORBID Crew: is what carries the case instead. It is not a weak substitute:
# if the clicks never landed there is no seat plan, auto-fill crews the capsule
# from a full pad, and "Crew: 'Ace' aboard" appears. Silence and an explicit
# Empty look identical in the outcome only once a plan exists -- making one is
# what the two clicks are for.
NAME vab-seat-emptied
CLAIM Choosing Empty for a seat keeps auto-fill from filling it.
KIND invariant
ARGS --kerbals e2e/fixtures/three_kerbals.json
ARGS --time-accel 1 --timeout 15.5 --frame-cap 30
ARGS --ui-click 4500,"Capsule (3m)##capsule_r1.5h3"
ARGS --sim-mouse 5500,0,960,540,LMB --sim-mouse 6000,0,960,540,RMB
ARGS --ui-click 6500,"Capsule (3m)##capsule_r1.5h3_1/Seat 1##s0"
ARGS --ui-click 7100,"##Combo_00/Ace"
ARGS --ui-click 7700,"Capsule (3m)##capsule_r1.5h3_1/Seat 1##s0"
ARGS --ui-click 8300,"##Combo_00/Empty"
ARGS --ui-click 9500,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what the palette and
# the dev roster need. Every scripted event here is shifted +3500ms
# because the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
EXPECT [crew] 3 kerbal(s) standing at
EXPECT [vab] part window: 'capsule_r1.5h3_1' seats 3
EXPECT [vab] launched 'Ship' (1 parts)
FORBID part window: nothing under the cursor
FORBID Crew:
FORBID no kerbal left
FORBID dropped the seat plan
FORBID FAILED
FORBID error:
LIMIT 90
