# a 6-seat capsule's part window is 479 px tall, far past the 300 px the layout can
# assume before imgui has drawn the window, so at a short window its lower rows sit
# outside the viewport where no player can reach them
#
# Placement used to be a one-off on the frame the window appears, so it placed against
# an estimate and never revisited it. It now re-runs once imgui reports the real size
# (AutoFitFrames counts down from 2) and pulls the window back inside the work area:
# at 1920x720 the window moves from y=371 to y=241, which is the difference between
# "Run Experiment" being a button and being a memory of one.
#
# The oracle is the click, not a rect. imgui does not register an item that fails its
# clip test, so --ui-click reports "not found" for a button the player never sees
# either -- the harness agreeing with what a player would get. power_test is the only
# ship with the 6-seat capsule (capsule_r2.25h4.5), and its window is the tallest
# there is.
NAME tall-part-window-stays-on-screen
CLAIM A tall part window re-fits so its lower rows stay on screen.
KIND invariant
ARGS --time-accel 1 --timeout 7 --width 1920 --height 720
ARGS --startship power_test,res/ships/power_test.json,Kerbin,rot-orbit
ARGS --ui-focus 2000,power_test/capsule_1
ARGS --sim-mouse 2100,0,CUR,CUR,RMB
ARGS --ui-click 3000,"power_test > Capsule (4.5m)##0/Run Experiment"
EXPECT ship=power_test part=0 (capsule_r2.25h4.5)
EXPECT recorded 'Low orbit observation
EXPECT [science] t=
FORBID FAILED
FORBID error:
