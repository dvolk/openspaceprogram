# The VAB's site dropdown was never under test: the retired --vab-site hook took
# a world-building id, the dropdown shows pad NAMES, and no case could reach the
# second pad. Now the case does what a player does -- open the dropdown, pick
# "Polar pad" -- and the launch lands where that pad stands.
#
# lat=90 is the oracle: the default pad stands at lat 0.29 / lon 270.3, so a
# dropdown pick that never reached the launch would leave the ship at the equator
# and fail the CHECK. The polar pad stands over ocean (alt_asl is negative,
# bme="ocean"), which is the other half of what the case pins: the site decides
# the ground under the ship, not just a label.
#
# Rows are the pads' display names; their ids are PushID'd so two pads sharing a
# name would make this path ambiguous and --ui-click would refuse rather than pick
# one at random. The combo only exists while the scenario is a pad scenario, so a
# case that picks an orbit bed first would find no ##vabsite at all.
NAME vab-launch-site-by-name
CLAIM The VAB site dropdown launches on the named pad.
KIND invariant
ARGS --timeout 15 --info-log --orbit-interval 1
ARGS --ui-click 8000,"VAB TopBar/##vabsite"
ARGS --ui-click 8500,"##Combo_00/Polar pad"
ARGS --ui-click 9500,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",racer
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"racer"
ARGS --ui-click 6300,"VAB TopBar/Load"
EXPECT [vab] launched 'racer' (4 parts)
EXPECT [scene] vab -> flight (enterFlight)
CHECK len(surf) >= 3
CHECK all(abs(s["lat"] - 90.0) < 0.01 for s in surf)
CHECK all(s["sit"] == "landed" for s in surf)
