# --dev-vehicles puts the testships back in the VAB's Load picker. transporter
# is marked "testship": true and sorts last, so it is absent by default and
# below the popup's fold with the flag: the scroll is what makes it reachable.
# The loaded part count is the witness that the def resolved, not just the name.
NAME vab-dev-vehicles
CLAIM Dev vehicles appear in the Load picker, below the fold until scrolled.
KIND invariant
ARGS --vab-empty --dev-vehicles --timeout 12
ARGS --ui-click 1500,"VAB TopBar/##vabload"
# The popup window is named after the combo id --ui-list reports. transporter
# is below the fold before the scroll, so it is not even in the item registry.
ARGS --ui-list 1900
ARGS --ui-scroll 2100,"##Combo_00",-20
ARGS --ui-click 2800,"##Combo_00/transporter"
ARGS --ui-click 3400,"VAB TopBar/Load"
EXPECT [vab] loaded transporter (5 parts)
EXPECT [vab] camera aimed at the build: 5 part(s)
CHECK '[uilist] window="##Combo_00" label="transporter"' not in out
FORBID FAILED
FORBID error:
