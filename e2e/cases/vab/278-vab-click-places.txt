# The VAB used to poll SDL_GetMouseState for the cursor and the left button, so
# a pushed --sim-mouse never reached the editor: --vab-place existed because
# there was no other way to place a part headless. The cursor now comes from the
# event queue, so a synthetic click drives the editor like it drives everything
# else -- and nothing in the suite tested that, which is how the freeze went
# unnoticed for as long as it did.
#
# A click in the 3D area places the armed part, so LAUNCH finds one part. The
# place is the click's: --vab-place used to fire vabPlace headlessly and print
# "[vab] place hook:" so a case could tell the two paths apart. The flag and its
# hook are gone now, so the launch count is the whole oracle -- and it is the
# better one, because it is what the player sees.
NAME vab-click-places
CLAIM A synthetic click places a part in the VAB.
KIND invariant
ARGS --timeout 9.5 --frame-cap 30
ARGS --ui-click 4500,"Capsule (3m)##capsule_r1.5h3"
ARGS --sim-mouse 5500,0,960,540,LMB
ARGS --ui-click 7000,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what the palette and
# the dev roster need. Every scripted event here is shifted +3500ms
# because the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
EXPECT [vab] launched 'Ship' (1 parts)
CHECK re.search(r"\[vab\] launched 'Ship' \((\d+) parts\)", out).group(1) == "1"
FORBID FAILED
FORBID error:
# The part is armed by a palette click now (--vab-arm is gone), so the case also
# shows that arm click selecting the row WITHOUT placing: the count is still exactly
# the one part the 3D click placed. What it cannot show is a click in the 3D area
# landing through a window -- that click is at 960,540, outside every window. 279
# covers that one.
