# "Clear" empties the workspace. It is destructive and the editor has no
# undo, so the card is the guard: Cancel must leave the tanker's seven parts
# alone (the later clear reports 7 removed, which is the proof), and the second
# pass confirms. Once empty, the button is greyed and the click is refused --
# the refusal is the assertion, not a click that went wrong.
#
# A palette part is armed BEFORE the clear. Clearing drops the tool too; the
# viewport click after the clear proves it, because a surviving armed part would
# root itself at the origin and the launch would carry 1 part instead of
# refusing. Save proves the name field was reset: it must fail as "untitled"
# rather than overwrite the cleared tanker.
NAME vab-clear
CLAIM Clear asks first, empties the workspace, then refuses when already empty.
KIND invariant
ARGS --width 1920 --height 1080 --timeout 17
ARGS --ui-click 8500,"Capsule (3m)##capsule_r1.5h3"
ARGS --ui-click 9200,"VAB TopBar/Clear"
ARGS --ui-click 9800,"Question/Cancel"
ARGS --ui-click 10600,"VAB TopBar/Clear"
ARGS --ui-click 11200,"Question/Clear"
ARGS --ui-click 12000,"VAB TopBar/Clear"
ARGS --sim-mouse 12600,0,960,540,LMB
ARGS --ui-click 13200,"VAB TopBar/Save"
ARGS --ui-click 14000,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",tanker
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"tanker"
ARGS --ui-click 6300,"VAB TopBar/Load"
CHECK re.search(r"\[vab\] cleared the workspace \(7 parts removed\)", out)
EXPECT [toast] Workspace cleared
EXPECT [vab] camera aimed at the build: 0 part(s)
EXPECT path="VAB TopBar/Clear" FAILED disabled
EXPECT [toast] Save FAILED: untitled
EXPECT [toast] Nothing to launch
FORBID launched
FORBID FAILED not found
FORBID FAILED ambiguous
FORBID error:
