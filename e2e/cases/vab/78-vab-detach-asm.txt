# Detaching a SUBTREE ROOT stashes the whole subtree as a subassembly, and the
# launch that follows carries only what is left.
#
# This used to run --vab-detach 1 on tanker. The hook selected the part by index,
# so the case never proved the part was reachable by picking it. It also sits
# behind the core from the editor's default angle, which is normal for a 3D
# scene -- a player orbits and clicks it, and --ui-focus says so plainly rather
# than picking a neighbour (#311). stager is a straight chain, so dec_1 is a
# subtree root that is pickable from any angle, and the stash arithmetic is the
# same shape: 3 parts go, 4 stay.
#
# The stash itself is asserted, not inferred from the launch count: the toast
# says it went to Subassemblies and how many came with it.
NAME vab-detach-asm
CLAIM Detaching a subtree root stashes it and launches only what remains.
KIND invariant
ARGS --width 1920 --height 1080 --timeout 15
ARGS --ui-focus 8500,dec_1
ARGS --sim-mouse 8600,0,CUR,CUR,LMB
ARGS --ui-click 9500,"VAB/Detach subtree"
ARGS --ui-click 11000,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",stager
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"stager"
ARGS --ui-click 6300,"VAB TopBar/Load"
CHECK re.search(r"\[vab\] select 4 dec_1", out)
CHECK re.search(r"\[vab\] detached dec_1 \(3 parts\)", out)
EXPECT [toast] Detached dec_1 (+2) to Subassemblies
CHECK re.search(r"\[vab\] launched 'stager' \(4 parts\)", out)
FORBID FAILED
