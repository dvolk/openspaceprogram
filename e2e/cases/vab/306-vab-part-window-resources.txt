# The part window is a dossier, not a seat picker: right-clicking a TANK opens it
# too, and what it shows is what that part carries. The stat rows go through uiText
# (#601's channel), so --ui-list prints them WITH the values the player reads, and
# this case pins both faces: seats and capacities per part, with EC in watt-hours
# because EC is stored energy and rides no mass.
#
# When this case was written the rows were plain imgui Text, so deleting any of them
# (the mutation was tried) left the suite green and only the stdout line could be
# asserted (#333). The dossier's Type/Mass/Size/Carries/staff rows and the shared
# part card now go through uiText, so the EXPECTs below are the player's own view and
# the CHECKs are the arithmetic the window implies: the "+ Nkg at launch" figure is
# the sum of the Carries rows, and the log's capacities are the same figures the rows
# print. The window spells a substance "Hydrogen" where the log says "H2" (#334):
# pinning either spelling moves when someone unifies them, which is the point.
#
# The --ui-list dump lands while the TANK's window is live: a part with no seats
# gets no seat rows, which is the "if the part has seats" half of the widget. The
# second right-click is the other half on the same window -- a capsule shows its
# seat AND its battery. One window at a time, so the capsule's aim also replaces
# the tank's dossier.
NAME vab-part-window-resources
CLAIM A tank's part window reports the resources it carries.
KIND invariant
ARGS --kerbals e2e/fixtures/three_kerbals.json
ARGS --width 1920 --height 1080 --time-accel 1 --timeout 17 --frame-cap 30
ARGS --ui-focus 9000,tank_r1.5h3_2
ARGS --sim-mouse 9100,0,CUR,CUR,RMB
ARGS --ui-list 9500
ARGS --ui-focus 10000,capsule_1
ARGS --sim-mouse 10100,0,CUR,CUR,RMB
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",tanker
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"tanker"
ARGS --ui-click 6300,"VAB TopBar/Load"
EXPECT [vab] part window: 'tank_r1.5h3_2' seats 0, carries 1410.2kg H2, 1410.2kg LOX
EXPECT [vab] part window: 'capsule_1' seats 1, carries 2000.0Wh EC
# The same figures, read off the card instead of off the log line: the trailing
# " text" marker (the CHECK below) says the row was DRAWN, which is what an imgui
# Text row used to make unassertable.
EXPECT [uilist] window="Fuel Tank (3m x 3m)##tank_r1.5h3_2" label="Mass: 282.040kg + 2820.360kg at launch"
EXPECT [uilist] window="Fuel Tank (3m x 3m)##tank_r1.5h3_2" label="Size: 3.0m dia x 3.0m"
EXPECT [uilist] window="Fuel Tank (3m x 3m)##tank_r1.5h3_2" label="Carries 1410.2kg Hydrogen"
EXPECT [uilist] window="Fuel Tank (3m x 3m)##tank_r1.5h3_2" label="Carries 1410.2kg LOX"
# Type + Mass + Size + two Carries rows, and no staff row (a tank has no seats). The
# count is the tripwire: it moves if a row is deleted, renamed or hidden by a clip.
CHECK len([l for l in out.split("\n") if l.rstrip().endswith(" text") and 'window="Fuel Tank (3m x 3m)##tank_r1.5h3_2"' in l]) == 5
CHECK 'label="Seat 1##s0"' not in out
# The card's own arithmetic: the "+ Nkg at launch" figure is the sum of its Carries
# rows (gameui.cpp sums def.capacity over everything but EC). An identity, not a
# figure, so a parts rebalance moves the numbers without moving the assertion. The
# 0.2 band covers three one-decimal printings. Both sides are window-qualified: the
# capsule's dossier opens 600ms later and would otherwise leak into the sums.
CHECK abs(float(re.search(r'window="Fuel Tank \(3m x 3m\)##tank_r1.5h3_2" label="Mass: [0-9.]+kg \+ ([0-9.]+)kg at launch', out).group(1)) - sum(float(v) for v in re.findall(r'window="Fuel Tank \(3m x 3m\)##tank_r1.5h3_2" label="Carries ([0-9.]+)kg', out))) < 0.2
# One quantity, two spellings, one set of numbers: the log's short names (#334) must
# still carry what the window's rows print. The log side is anchored on its own tag,
# so a window row can never be compared against itself.
CHECK re.findall(r'\[vab\] part window: [^\n]* carries ([0-9.]+)kg H2', out) + re.findall(r'\[vab\] part window: [^\n]*, ([0-9.]+)kg LOX', out) == re.findall(r'window="Fuel Tank \(3m x 3m\)##tank_r1.5h3_2" label="Carries ([0-9.]+)kg', out)
FORBID part window: nothing under the cursor
FORBID FAILED
FORBID error:
