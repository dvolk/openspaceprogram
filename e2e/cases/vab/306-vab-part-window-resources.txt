# The part window is a dossier, not a seat picker: right-clicking a TANK opens it
# too, and what it shows is what that part carries. The stat rows are plain imgui
# Text, so the "[vab] part window" line is the testable face of that half -- seats
# and capacities per part, with EC in watt-hours because EC is stored energy and
# rides no mass.
#
# What this does NOT pin is the Text itself: --ui-list registers items, not
# labels, so deleting the Carries/Mass/Size rows would leave this case green while
# the numbers they print stay correct. It pins the data the window is built from
# and the seat rows it does or does not create. Closing that gap needs a way for
# the harness to read Text rows, not another assertion here.
#
# The --ui-list dump lands while the TANK's window is live: a part with no seats
# gets no seat rows, which is the "if the part has seats" half of the widget. The
# second right-click is the other half on the same window -- a capsule shows its
# seat AND its battery. One window at a time, so the capsule's aim also replaces
# the tank's dossier.
NAME vab-part-window-resources
CLAIM A tank's part window reports the resources it carries.
KIND invariant
ARGS --kerbals e2e/fixtures/three_kerbals.json
ARGS --width 1920 --height 1080 --time-accel 1 --timeout 17 --frame-cap 30
ARGS --ui-focus 9000,tank_r1.5h3_2
ARGS --sim-mouse 9100,0,CUR,CUR,RMB
ARGS --ui-list 9500
ARGS --ui-focus 10000,capsule_1
ARGS --sim-mouse 10100,0,CUR,CUR,RMB
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",tanker
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"tanker"
ARGS --ui-click 6300,"VAB TopBar/Load"
EXPECT [vab] part window: 'tank_r1.5h3_2' seats 0, carries 1410.2kg H2, 1410.2kg LOX
EXPECT [vab] part window: 'capsule_1' seats 1, carries 2000.0Wh EC
CHECK 'label="Seat 1##s0"' not in out
FORBID part window: nothing under the cursor
FORBID FAILED
