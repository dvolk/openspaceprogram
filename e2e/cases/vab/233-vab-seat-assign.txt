# WHO flies, said by the player instead of by the front of the FIFO line. The
# part window (right-click a capsule in the VAB) is the feature: 'Bram' goes up
# because the window said so -- and 'Ace', first in line, stays on the pad,
# because naming any seat turns auto-fill off entirely.
#
# This used to be blocked by #311: tanker is seven parts, and a right-click at a
# fixed pixel picks whatever is under it -- measured, 960,540 lands on
# 'tank_r1.5h3_2', a part with no seat to name. --ui-focus is what unblocked
# it: a bare PART_ID names a VAB build part and the game projects IT to a pixel,
# so the case names the capsule instead of gambling on a coordinate.
NAME vab-seat-assign
CLAIM Naming a VAB seat flies that person and turns auto-fill off.
KIND invariant
ARGS --kerbals e2e/fixtures/three_kerbals.json
ARGS --time-accel 1 --timeout 19 --frame-cap 30
ARGS --ui-focus 9000,capsule_1
ARGS --sim-mouse 9100,0,CUR,CUR,RMB
ARGS --ui-click 10000,"Capsule (2m)##capsule_1/Seat 1##s0"
ARGS --ui-click 10600,"##Combo_00/Bram"
ARGS --ui-click 12000,"VAB TopBar/LAUNCH"
# Reached the way a player reaches the editor: Title Menu -> New Game -> Start, then
# the 4 key.
# Game Debug turns on dev vehicles, which is what puts this def in the
# Load picker; the filter narrows the roster to one row, and row + Load
# do the rest. Same vabLoad() either way, so the assertions below are
# unchanged -- and every scripted event here is shifted +7000ms because
# the editor opens at 2.6s, not at boot.
ARGS --ui-click 1000,"Title Menu/New Game"
ARGS --ui-click 1600,"New Game/Start"
ARGS --sim-press 2600,0,4
ARGS --sim-press 3100,0,F1
ARGS --ui-click 3600,"Game Debug/Dev vehicles in the VAB picker"
ARGS --sim-press 4100,0,F1
ARGS --ui-type 4600,"VAB TopBar/##vehfilter",tanker
ARGS --ui-click 5100,"VAB TopBar/##vabload"
ARGS --ui-click 5700,"tanker"
ARGS --ui-click 6300,"VAB TopBar/Load"
EXPECT [vab] part window: 'capsule_1' seats 1
EXPECT Crew: 'Bram' aboard 'tanker' part 0 (1/1)
EXPECT [vab] launched 'tanker' (7 parts)
FORBID Crew: 'Ace'
FORBID no kerbal left
FORBID FAILED
FORBID error:
LIMIT 90
