# A jump that never leaves contact must still end. The post-jump latch used to
# release when Bullet contact cleared, but a kerbal that hops into the launch
# pad's wall has the wall eat the kick and slides back onto the floor: contact
# never breaks (measured in the stuck state: contact=1, radial velocity ~0,
# altitude inside the standing band, contact normal exactly radial), the latch
# sticks, and it glides along the ground in space mode forever -- W burns suit
# hydrazine as RCS instead of walking and the suit never stands back up. The
# latch now releases on the outward kick being spent, which gravity guarantees.
NAME eva-jump-padwall
CLAIM A jump into the pad wall ends instead of gliding along the ground forever.
KIND invariant
# --timeout is load-bearing, not slack: the wall bump spins the suit up to the
# 6 rad/s slew cap and it needs ~2 s to right itself, so an 8 s run leaves that
# spin inside the last-4 s window and the |w| check fails.
ARGS --timeout 17 --eva-log --att-log --orbit-interval 0.5 --sim-press 8000,5000,W --sim-press 9000,0,SPACE --frame-cap 30
# Reached by the Save/Load sheet, not --load: Game Debug ticks the e2e
# fixture root, the sheet picks the "fixtures" game, the slot filter
# narrows 50 saves to this one row, and row + Load button do the rest.
# Same load_game() either way, so the assertions below are unchanged --
# and every scripted event here is shifted +5000ms because the load now
# lands at 4s, not at boot. The PERIOD presses climb the warp ladder
# where --time-accel used to: a sheet load starts paused.
ARGS --sim-press 500,0,F1
ARGS --ui-click 1000,"Game Debug/Load e2e fixture saves"
ARGS --sim-press 1500,0,F1
ARGS --ui-click 2000,"Title Menu/Save/Load"
ARGS --ui-click 2500,"fixtures"
ARGS --ui-type 3000,"Save/Load/##filter",save_eva_padwall
ARGS --ui-click 3800,"save_eva_padwall"
ARGS --ui-click 4000,"Save/Load/Load##saveload"
ARGS --sim-press 4300,0,PERIOD
EXPECT Loaded game from e2e/fixtures/save_eva_padwall (active: kerbal)
EXPECT [toast] Loaded fixtures/save_eva_padwall
FORBID error:
CHECK len(eva) > 10
# Checked over the last 4 s of the run, not a fixed offset from the start: when
# the bump happens moves with frame pacing.
CHECK all(e["mode"] == "ground" for e in eva if e["t"] > last(eva)["t"] - 4.0)
# Stuck in space mode, the held W burns the suit tank: 0.36 kg here vs 0.03 kg
# when the latch releases.
CHECK first(eva)["mass"] - last(eva)["mass"] < 0.2
CHECK max(a["wnorm"] for a in att if a["t"] > last(att)["t"] - 4.0) < 1.0
# "Stood back up" = the long axis (nose = local +Z) along the local vertical,
# measured against the kerbal's own position rather than a pre-jump sample (the
# first sample lands mid-settle, |w| ~0.9 rad/s).
CHECK all(sum(n*p for n,p in zip(a["nose"], last(eva)["pos"])) / sum(p*p for p in last(eva)["pos"])**0.5 > 0.9 for a in att if a["t"] > last(att)["t"] - 4.0)
