# A walker takes its suit from the home pad pool, so a roster of one can only
# name one walker. The second keeps the suit the def minted, and make_part never
# gives a suit a KerbalProfile -- so place_vehicle mints an anonymous one (id 0,
# which refuseDoubleClaimId treats as claiming nothing) carrying the requested
# name (#291). This case pins the spawn: the second walker is the anonymous one,
# the named one is not. What it does NOT pin is the profile surviving a save +
# load -- that needs the walker aboard a capsule, and #394 covers what an
# id-0 person is good for.
NAME anonymous-walker-keeps-name
CLAIM A walker spawned on a spent pool keeps its name on an anonymous profile.
KIND invariant
ARGS --kerbals e2e/fixtures/tiny_kerbals.json --time-accel 1 --timeout 6
ARGS --startship Solo,res/ships/kerbal.json,Kerbin,pad
ARGS --startship k2,res/ships/kerbal.json,Kerbin,rot-orbit
EXPECT Roster: 1 kerbal(s) from e2e/fixtures/tiny_kerbals.json
EXPECT [crew] pool spent: 'k2' is anonymous
FORBID [crew] pool spent: 'Solo' is anonymous
EXPECT Timeout reached
FORBID error:
FORBID Assertion
LIMIT 60
