# A FREE EVA kerbal rebuilt from a save must walk like the live one. The suit's
# feet are frictionless on purpose (the Kerbal ctor, src/eva.h): the walk force
# goes in at the COM, so foot friction pairs with it into a tipping couple the
# attitude authority cannot out-torque. That grip used to be applied at the two
# live build sites only, so the load path rebuilt the hull with the default
# friction and the kerbal rolled itself over the moment it tried to walk: |w|
# peaks near 3.9 rad/s and stays up there tick after tick, and the long axis ends
# up horizontal. The axis is the tell, and so is WHEN the rate is high -- see the
# CHECKs at the bottom, which #1152 forced a rewrite of.
NAME eva-walk-reload
CLAIM A reloaded kerbal walks like a live one; foot friction is rebuilt.
KIND invariant
ARGS --timeout 13 --eva-log --att-log --orbit-interval 0.2 --sim-press 6500,2500,W --frame-cap 30
# Reached by the Save/Load sheet, not --load: Game Debug ticks the e2e
# fixture root, the sheet picks the "fixtures" game, the slot filter
# narrows the fixture list to this one row, and row + Load button do
# the rest. Same load_game() either way, so the assertions below are
# unchanged. The PERIOD presses climb
# the warp ladder where --time-accel used to: a sheet
# load starts paused.
ARGS --sim-press 500,0,F1
ARGS --ui-click 1000,"Game Debug/Load e2e fixture saves"
ARGS --sim-press 1500,0,F1
ARGS --ui-click 2000,"Title Menu/Save/Load"
ARGS --ui-click 2500,"fixtures"
ARGS --ui-type 3000,"Save/Load/##filter",save_eva_ground
ARGS --ui-click 3800,"save_eva_ground"
ARGS --ui-click 4000,"Save/Load/Load##saveload"
ARGS --sim-press 4300,0,PERIOD
EXPECT Loaded game from e2e/fixtures/save_eva_ground (active: kerbal)
EXPECT [toast] Loaded fixtures/save_eva_ground
FORBID error:
FORBID FAILED
CHECK len(eva) > 10
# The first sample sits above the deck until the load's contact settles, so the
# state checks run from a second after the load (sim time starts at the saved
# clock, not 0).
CHECK all(e["mode"] == "ground" for e in eva if e["t"] > first(eva)["t"] + 1.0)
# It walks: 2.5 s at kWalkSpeed covers ~6 m against a 1.5 m bar, and stops when
# W comes up.
CHECK max((e["vel"][0]**2 + e["vel"][1]**2 + e["vel"][2]**2)**0.5 for e in eva) > 1.5
CHECK ((last(eva)["pos"][0] - first(eva)["pos"][0])**2 + (last(eva)["pos"][1] - first(eva)["pos"][1])**2 + (last(eva)["pos"][2] - first(eva)["pos"][2])**2)**0.5 > 1.5
CHECK (last(eva)["vel"][0]**2 + last(eva)["vel"][1]**2 + last(eva)["vel"][2]**2)**0.5 < 0.5
# UPRIGHT THE WHOLE WAY: the long axis (nose = local +Z) still points where it started.
# This is the tip-over signature -- the defect leaves it horizontal. It is also blind to a
# turn ABOUT that axis, which on the ground is the kerbal yawing to face somewhere, so it
# cannot see the two turns below and does not try to.
CHECK all(sum(n*f for n,f in zip(a["nose"], first(att)["nose"])) > 0.9 for a in att if a["t"] > first(att)["t"] + 1.0)
# NOT SPINNING -- with the rate half keyed on WHERE the rate is high, which is what #1152
# forced. Under the old 0.1 m hull skin the suit's attitude servo could not actuate at all:
# every one of the 41 attlog rows read |w| <= 0.032, so the old "max |w| < 1.0" was pinning
# an INABILITY to turn rather than an absence of tumble (measured both ways:
# OSP_HULL_MARGIN=0.1 -> max 0.032, at the shipped 0 -> max 6.0). The skin was worth about
# a third of the kerbal's rotational inertia, the same coupling src/physics.cpp's margin
# note shouts about for rcs_test. With it off, the servo gets its way twice per run: once at
# the load's contact settle (t~3.3) and once at the W press (t~5.3), which take the kerbal
# 41 deg about its own long axis and back. Both are point-to-point, not a spin: the rows
# either side read 0.0001, and nose.dot stays 1.00005 throughout.
# What CANNOT be pinned is the peak. The servo slews at kMaxRate (src/eva.cpp) and the
# 0.234 s attlog lands at whatever phase -- rows above 1 rad/s read {2.7080, 1.3540},
# {2.7080, 6.0000}, {1.3540, 1.3540} across three runs -- so a ceiling on the peak is a bet
# on sampling phase, which is how this case went flaky. What is pinnable is that there are a
# couple of such samples, not a run of them: the friction defect this case is named for
# holds a high rate tick after tick. And the walking window itself -- where that defect
# shows, and where these two turns are over -- stays quiet. The window is relative for the
# same reason as the state checks above; an absolute t here sat 0.6 s from the W-press turn.
CHECK len(att) >= 30
CHECK sum(1 for a in att if a["wnorm"] > 1.0) <= 3
CHECK max(a["wnorm"] for a in att if a["t"] > first(att)["t"] + 3.0) < 1.0
CHECK last(att)["wnorm"] < 0.01
# AND THE SERVO ACTUATES, which is the half the old ceiling was hiding: with the skin back on
# every CHECK above passes on a kerbal that never turns (max |w| 0.032). The turns are ABOUT
# the long axis, so the nose test cannot see them; they show up as the hull's right vector
# swinging around it. min right.dot over the run is 0.7504 = cos 41.0 deg (2/2 runs at the
# shipped margin) and 1.0000 with the skin back on. Pinned on the axis geometry rather than
# on a rate sample, so sampling phase cannot undo it.
CHECK min(sum(r*f for r,f in zip(a["right"], first(att)["right"])) for a in att) < 0.8
