# A pad ship must spawn AT its resting height, not above it. build_ship's lift
# reads the parts' inflated hull bottoms and the pad's OWN collision margin: a
# space pad is a static convex hull (buildings.cpp), so the pair that meets
# under a pad ship is hull + hull, never the terrain mesh's margin. The old
# hardcoded 0.6 (terrain 0.5 + hull 0.1) hung the racer ~0.4 m high, so it
# free-fell for the first third of a second: alt read 9.3 -> 9.1 -> 8.9 and
# |v| peaked at 1.95 m/s. Both margins are env-tunable (OSP_HULL_MARGIN,
# OSP_TERRAIN_MARGIN), so this pins the property rather than an altitude.
NAME pad-rest-settle
ARGS --time-accel 1 --timeout 3 --dbg-log --orbit-interval 0.1 --startship racer,res/ships/racer.json,Kerbin,pad
FORBID GL_
FORBID error:
CHECK len(dbg) > 10
CHECK all(d["v"] < 0.5 for d in dbg)
CHECK max(d["alt"] for d in dbg) - min(d["alt"] for d in dbg) < 0.15
