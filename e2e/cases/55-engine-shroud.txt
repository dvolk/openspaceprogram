# Engine shroud: the stager's upper engine has a decoupler attached below
# it (so the shroud draws over it), while its booster engine sits at the
# ship's tail (bare). Both declare the shroud in the catalog, so the
# build-time snapshot logs one shrouded and one bare.
# Anchors are the [shroud] snapshot lines (src/vehicle.cpp
# build_ship_structure); the FORBIDs catch a broken shroud asset (a
# placeholder-cube mesh import / hot-pink texture, or a GL error on the
# extra draw).
NAME engine-shroud
ARGS --scenario pad --ship res/ships/stager.json --timeout 12
EXPECT [shroud] engine_upper: shrouded
EXPECT [shroud] engine_boost: bare
FORBID GL_
FORBID error:
FORBID could not import
FORBID could not load
