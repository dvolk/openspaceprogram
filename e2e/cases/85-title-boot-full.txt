# Boot to the title screen with the BIG system (solar_system_full.json,
# 240 bodies). This is the path that used to sit on a blank window for ~7s
# while load_system built every body's terrain + collision. The loading
# scene now presents a "loading..." frame as early as the font is ready and
# refreshes it per body (see drawLoadingFrame in main.cpp + the progress
# hook in load_system). e2e can't assert on the pixels, but it proves the
# big system still boots cleanly to the title with the new frames in the
# path (no GL errors / crashes from the early present).
NAME title-boot-full
ARGS --system res/solar_system_full.json --timeout 6
EXPECT Loaded system 'res/solar_system_full.json'
EXPECT [boot] no vessel: title screen
EXPECT [title] backdrop:
EXPECT [scene] flight -> title (enterTitle)
EXPECT Main loop starting
FORBID GL_
FORBID error:
LIMIT 180
