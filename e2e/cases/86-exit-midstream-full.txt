# Exit while the BIG system's terrain is still streaming.
#
# This guards the light/heavy split (TerrainBody::ready / BuildRootGeoms /
# AttachRoot). On a 240-body system the heavy phase (root terrain + shells)
# streams on the worker for ~6s. If the player quits early, shutdown runs
# job.abort() (drops the queued jobs, runs at most the in-flight one), so
# the AttachRoot CONTINUATIONS of most bodies never run (poll() only happens
# in the main loop, which has already exited) -- most bodies are left
# unattached. ~TerrainBody then deletes all six patch slots: they must be
# nullptr (value-initialized in terrain.h) or this segfaults. A short
# --timeout guarantees a large unattached set at exit.
NAME exit-midstream-full
ARGS --system res/solar_system_full.json --timeout 1
EXPECT Loaded system 'res/solar_system_full.json'
EXPECT Main loop starting
FORBID free(): invalid pointer
FORBID free(): corrupted
FORBID double free
FORBID invalid user data pointer
FORBID Segmentation fault
FORBID GL_
FORBID error:
LIMIT 90
