# One person in two seats. The window greys the second one out, but the plan can
# still go stale -- a system switch empties the pad, an earlier launch took the
# suit away. The launch is REFUSED before the ship exists rather than built with
# a seat the pad cannot fill, because a ship that flies half-crewed reads like a
# success.
#
# The first seat is the player's own: place the capsule, right-click it, pick the
# seat, pick Ace. The second is not reachable by hand, and the case now PROVES
# that instead of asserting it in a comment -- the dropdown lists an already-
# seated person as "Ace  (seated)" inside a BeginDisabled (drawVabPartWindow's
# seat rows), and --ui-click refuses the row as disabled. So the UI cannot build
# this plan on purpose, and --vab-assign is how the case gets the plan into the
# stale state the refusal guards. That makes this the exception rather than the
# rule.
NAME vab-seat-two-seats
ARGS --vab-empty --kerbals e2e/fixtures/three_kerbals.json
ARGS --time-accel 1 --timeout 12 --frame-cap 30
ARGS --ui-click 1000,"Capsule (3m)##capsule_r1.5h3"
ARGS --sim-mouse 2000,0,960,540,LMB
ARGS --sim-mouse 2600,0,960,540,RMB
ARGS --ui-click 3200,"Capsule (3m)##capsule_r1.5h3_1/Seat 1##s0"
ARGS --ui-click 3600,"##Combo_00/Ace"
ARGS --ui-click 4400,"Capsule (3m)##capsule_r1.5h3_1/Seat 2##s1"
ARGS --ui-click 4800,"##Combo_00/Ace  (seated)"
ARGS --ui-click 5000,"##Combo_00/Empty"
ARGS --vab-assign 5200,0,1,Ace
ARGS --ui-click 6000,"VAB TopBar/LAUNCH"
# The UI's own guard, pressed rather than described.
EXPECT path="##Combo_00/Ace  (seated)" FAILED disabled
# Pin WHICH refusal: the harness has a second disabled branch, "disabled at
# release" (uiinput.cpp:185), and its line contains the text above. This case is
# about the row being greyed out when the combo is drawn (drawVabPartWindow); if a
# click ever survives to release, the gate this asserts is no longer the one that
# stopped it. Same reason 236 forbids it.
FORBID FAILED disabled at release
FORBID FAILED MISMATCH
EXPECT [vab] launch refused: 'Ace' cannot sit in two seats
EXPECT [toast] Launch refused: 'Ace' cannot sit in two seats
FORBID [vab] launched
FORBID Crew:
FORBID not found
FORBID ambiguous
FORBID Assertion
FORBID Segmentation
FORBID GL_
FORBID error:
