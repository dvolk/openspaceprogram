# The editor opened with nothing to fly sits on [title, vab], so "Back to game"
# pops to the TITLE screen rather than dropping into a flight scene with no
# vessel in it -- which is what the old single-scene model did, and why the
# flight readouts were reachable with nothing to read out.
#
# The camera round trip is asserted the same way case 60 does: the parked and
# restored lines must name the same target and distance (3 radii out on Kerbin,
# the shipless default).
NAME vab-back-to-title
ARGS --vab-empty --vab-close 2000 --timeout 8
EXPECT [scene] title -> vab (push)
EXPECT [scene] vab -> title (pop)
EXPECT [cam] parked: orbit focus=Kerbin dist=
EXPECT [cam] restored: orbit focus=Kerbin dist=
CHECK len(re.findall(r"\[cam\] (?:parked|restored): orbit focus=Kerbin dist=([\d.]+) m", out)) == 2
CHECK len(set(re.findall(r"\[cam\] (?:parked|restored): orbit focus=Kerbin dist=([\d.]+) m", out))) == 1
FORBID GL_
FORBID error:
