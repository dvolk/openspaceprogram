# #266's active-ship guard: save.json is save_roster_named with "active_ship"
# pointed at v1, which is the KERBAL -- and that kerbal is aboard v0 'racer'.
# The writer cannot produce this (it records g.ship, and a kerbal inside a ship
# is never the active vehicle), so it is a hand-authored shape. The load must
# refuse to hand the camera to a kerbal parked in a capsule and fall back to the
# first vehicle in the save's order instead.
NAME load-active-ship-is-aboard-crew
ARGS --load e2e/fixtures/save_active_is_crew --time-accel 1 --timeout 3 --eva 2500
EXPECT [crew] loaded 'Ash' aboard 'racer'
EXPECT Loaded game from e2e/fixtures/save_active_is_crew (active: racer)
EXPECT EVA: 'Ash' out of 'racer' part 0
FORBID (active: Ash)
FORBID --eva: no crew aboard
FORBID GL_
FORBID error:
LIMIT 60
