# with --spin-log printing the ship's rotational state. A ship is ONE rigid
# body now, so there is a single angular velocity and no inter-part contact
# torque to report -- what is left that can still spin a passive ship is the
# tidal (differential-gravity) torque, so that is pinned alongside the state
# it acts on. Also guards against a physics regression that NaNs the
# spin/torque math, and against breaking the hand-built radial-test ship
# construction, which bypasses build_ship() entirely (it links parts into the
# tree itself and places the whole ship with one placeShip call).
