NAME roll-ailerons
CLAIM A plane rolls with its ailerons: a pair of ailerons at the skiff's wing trailing edge answers the roll stick and banks the hull past 30 deg by t=3 s of a stick held from t=1 s, where before #563 nothing on this airframe could roll it at all.
KIND invariant
ARGS --time-accel 1 --startship skiff,res/ships/skiff.json,Kerbin,flying-cruise
ARGS --sim-steps 480 --drag-log
ARGS --sim-press 1000,2000,Q
EXPECT [drag]
CHECK len(drag) >= 5
# Up is the ship's up axis against the world's: 1.00 wings-level, 0.93 at t=2 s,
# 0.72 at t=3 s and 0.69..0.70 (44-46 deg) from there on. #568's pod hull gave this
# airframe its first reaction wheel (capsule torque 100 N m), so the case is no longer
# an aero-only proof -- but #566 measured this same pair billing 8.91 kN m of roll at
# full deflection at cruise speed, so the wheel is 1% of the bank's author.
# The pair is 0.56 m2 per side at the trailing edge; the mount convention that makes
# it lie FLAT is a spanwise `normal` (the child's srf node normal is its span, so a
# +Y normal stands the aileron on edge -- that is #566's lesson).
# Beta never breaks 1.2 deg on this run: a correctly oriented aileron rolls without
# yawing. The band is 3.0 rather than 1.2 so the case guards "it does not weathervane
# away" without pinning this run's wiggle.
CHECK min(d["up"] for d in drag if d["t"] >= 2.0) < 0.80
CHECK all(abs(d["beta"]) < 3.0 for d in drag if d.get("beta") is not None)
# And it comes back: release the stick at t=3 s and the airframe still shows the same
# bank at t>=5 s -- 0.69..0.70, no self-righting and no wheel levelling it either,
# which is what a plane does.
CHECK all(d["up"] < 0.85 for d in drag if d["t"] >= 5.0)
FORBID error:
