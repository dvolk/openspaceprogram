NAME roll-ailerons
CLAIM A plane rolls with its ailerons: a pair of ailerons at the skiff's wing trailing edge answers the roll stick and banks the hull past 28 deg by t=3 s of a stick held from t=1 s, where before #563 nothing on this airframe could roll it at all.
KIND invariant
ARGS --time-accel 1 --startship skiff,res/ships/skiff.json,Kerbin,flying-cruise
ARGS --sim-steps 480 --drag-log
ARGS --sim-press 1000,2000,Q
EXPECT [drag]
CHECK len(drag) >= 5
# Up is the ship's up axis against the world's: 1.00 wings-level, 0.97 at t=2 s,
# 0.88 at t=3 s and 0.86..0.87 (29-31 deg) from there on. #568's pod hull gave this
# airframe its first reaction wheel (capsule torque 100 N m), so the case is no longer
# an aero-only proof -- but #566 measured this same pair billing 8.91 kN m of roll at
# full deflection at cruise speed, so the wheel is 1% of the bank's author.
# The pair is 0.56 m2 per side at the trailing edge; the mount convention that makes
# it lie FLAT is a spanwise `normal` (the child's srf node normal is its span, so a
# +Y normal stands the aileron on edge -- that is #566's lesson).
# Beta never breaks 1.2 deg on this run: a correctly oriented aileron rolls without
# yawing. The band is 3.0 rather than 1.2 so the case guards "it does not weathervane
# away" without pinning this run's wiggle.
# These bands are looser than the ones #563 shipped with (0.80 / 0.85) because #567
# moved both terms of the roll equation and not the same way: the pair's station went
# 5.40 -> 6.40 m, so its moment is up 18%, while the 16 x 1.5 wing puts 96 kg out to
# 8 m of tip and the hull's roll inertia with it (+88%). The hull answers the same stick
# at about half the rate -- 0.24 rad/s about the nose at full stick, off --att-log,
# against the 0.40 the 12 m wing gave. Rig travel is still not authority (#566/#509);
# buying the bank back means a bigger tab, which is #588 rather than this case's.
# The first band is about the RATE, not the destination. Measured Up is 1.00 at t=1 s,
# 0.98 at t=2 and 0.92 at t=3 (unwinded it was 1.00 / 0.97 / 0.88 -- Kerbin's column took
# ~28 m/s off the air a gravity-keyed bed spawns at, and aileron authority goes with the
# air), so "under 0.95 from t=3 on" fails as soon as roll
# authority drops, where a bank-only pin would still pass a hull that took eight seconds
# to lean over.
CHECK all(d["up"] < 0.95 for d in drag if d["t"] >= 3.0)
CHECK all(abs(d["beta"]) < 3.0 for d in drag if d.get("beta") is not None)
# And it comes back: release the stick at t=3 s and the airframe still shows the same
# bank from t=6 s on -- 0.88..0.89, no self-righting and no wheel levelling it either,
# which is what a plane does. The band starts a second later than it did unwinded, for the
# same reason as the note above; the bank itself is shallower by 0.01-0.02.
CHECK all(d["up"] < 0.90 for d in drag if d["t"] >= 6.0)
