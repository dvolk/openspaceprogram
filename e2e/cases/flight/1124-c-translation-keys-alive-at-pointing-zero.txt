NAME translation-keys-alive-at-pointing-zero
CLAIM With the pointing dial at 0 the same ring still pushes at the full ask: the two RCS doors are independent and only the steering half went dark (#1124).
KIND invariant
# The mirror of flight/1067-c, which shows pointing alive with the KEYS at zero. Here
# the dimmer that is at zero is the pointing one, and the translation half must not
# notice: N held asks the ring's full 120 N along +X -- flight/110's figure for this
# fixture, with no lim= on the [rcs] row because the keys' dial is untouched -- and each
# firing bell spends its whole 60 N rating.
#
# Meanwhile the attitude columns read 0/0/0 live against 138/0/138 hardware, which is
# the shape this dial makes on purpose: 0 % is the dimmer's END, not the switch. The
# rows are still there (rcs_on=1, and the hull still HAS a ring), they are simply not
# allowed any gas. rcs_attitude_enabled=0 would remove them instead, and the live rcs=
# figure would come from a hull with no rows at all -- flight/595's off-switch shape.
# flight/1124-d is the case that shows the two shapes differ where it shows: a law's
# ask.
ARGS --time-accel 1 --sim-steps 480 --startship rcs_box_pair,res/ships/rcs_box_pair.json,Kerbin,inertial-orbit --steering-log --drag-log --fuel-log --rcs-att-frac 0 --sim-press 2000,3000,N
EXPECT RCS: attitude limited to 0% of what the ring leaves after the keys
EXPECT [rcs] cmd=(120 0 -0)N ach=(120 0 -0)N
EXPECT rcs=0/0/0 rcs_hw=138/0/138 rcs_on=1 att_lim=0%
FORBID error:
FORBID cmd=(60 0
# The bell names ride in a CHECK, not an EXPECT: a bracketed [-Z] reads as a character
# class to the case linter, which is right that EXPECT is a substring test.
CHECK "box_l[-Z]=60N box_r[-Z]=60N" in out
CHECK len(re.findall(r'\[rcs\]', out)) == 3
# The tank pays, and only the keys are firing: no attitude key is pressed in this case,
# so every gram that left went into translation. A dial that leaked into translation
# would show fewer newtons and less gas.
CHECK first(fuel)["groups"][0]["N2H4"][0] - last(fuel)["groups"][0]["N2H4"][0] > 0.05
CHECK all("att_lim=0%" in l for l in out.splitlines() if "[steerlog]" in l)
