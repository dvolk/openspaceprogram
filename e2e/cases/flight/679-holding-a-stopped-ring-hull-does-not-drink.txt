# A ring of bells turns a hull with no wheels and no armed engine (#595), and #677 proved
# the kill-rot law asks it to. What #679 found is that the law keeps asking after the hull
# has STOPPED, and the tank keeps falling: hold kill-rot on rcs_test, watch |w| reach
# 0.0000 at t=6.65, and --drain-log prints 0.08 kg/s for the next two and a half seconds
# while the key stays down. Integrated over that run: 0.51 kg, of which ~0.27 kg left the
# tank doing nothing at all -- about 5 kg a minute of hydrazine to hold a still ship.
#
# The culprit is not the law and not the ring's rating. It is a row with a HAIR of
# authority. Vehicle hands the torque solver one row per bell, priced cross(arm,dir) x
# thrust, and the solver (actuators.h) fits a demanded vector with no notion of what a row
# COSTS. rcs_test's four boxes each carry one bell whose axis passes within microns of the
# COM: its lever is ~1e-5 N m, so its line's capacity is ~1e-5, and the residual ask of
# 0.0002 N m is ten times that. The solver loads the bell to its LIMIT -- the descent is
# happy with any split along a shared direction, so it gives the weak line its whole
# capacity and the strong bells the rest -- and applyRcsForce then bills a FULL 120 N bell
# for the 1e-5 N m it delivered. Measured with a temporary probe: ask 0.0002 N m, four bells
# at s=1.0, 120-240 N of gas every other substep, |w| = 0.0000 the whole time.
#
# The fix is in row building, not in the solve: a bell under 0.1% of its own ring's best
# lever is not a steering actuator at all. It stays fully creditable to rcsPlan for PUSHING
# -- that is what a bell through the COM has always been good for -- it just cannot be spent
# on pointing. tests/test_authority.cpp pins the cut and the saturated-bell arithmetic in a
# fixture; this case is the same fact flying, and it is the first RCS case in the battery
# that reads --drain-log, because the fuel print's one decimal cannot see a 0.1 kg burn.
#
# The stop itself still pays: 0.056 kg/s while 138 N m is putting 0.88 rad/s down. Post-fix
# totals for these ARGS: ~0.10 kg for the whole run, against 0.51 kg before it, and every
# drain row after t=7.4 is 0.000.
NAME holding-a-stopped-ring-hull-does-not-drink
CLAIM Holding kill-rot on a ring-steered hull that has already stopped drinks nothing, while the stop that got it there still costs.
KIND invariant
ARGS --time-accel 1 --startship rcs_test,res/ships/rcs_test.json,Kerbin,inertial-orbit
ARGS --slew-log --drain-log --no-paint
ARGS --sim-press 3000,600,S,6000,3000,X
ARGS --timeout 12
LIMIT 40
EXPECT [drainlog]
FORBID error:
FORBID FAILED
# S (pitch) for 600 ms at 3.0 s is the disturbance; X (kill-rot) is HELD from 6.0 to 9.0 s,
# which is what the player does -- X is an override, not a latch. Same bed as
# flight/677-kill-rot-stops-a-ring-only-hull, so the two cases read the same fixture.
CHECK len(slew) >= 15
CHECK len(drainlog) >= 15
# THE HULL DID STOP, and stayed stopped while the key was still down. Without this the
# drain pins below could pass by the ring going dead, which is #677's bug wearing the
# opposite face.
CHECK max(s["wnorm"] for s in slew) > 0.25
CHECK min(s["wnorm"] for s in slew) < 0.01
CHECK all(s["wnorm"] < 0.02 for s in slew if s["t"] > 8.0)
# THE RING WAS WORKING DURING THE STOP: tau_spent sits on the 138 N m pitch rating, and
# the ring drank while it did. rcs_test is priced at 276/138/138 N m (R/P/Y) by
# --steering-log; the ring's leverage is unchanged by the fix, and this is where the
# fix must NOT show up.
CHECK max(s["tau_spent"] for s in slew) > 120
CHECK max(r["rates"][0] for r in drainlog if r["t"] < 7.0) > 0.03
# THE HOLD COSTS NOTHING. The stop is done by t=6.7; a --drain-log row averages its own
# window, so the first row that cannot still be carrying the stop's spend is t >= 7.4.
# Before the fix these rows read 0.026-0.098 kg/s steady (the spread is when a wall-clock
# key release lands, #1054); post-fix they print 0.000.
CHECK all(r["rates"][0] < 0.005 for r in drainlog if r["t"] >= 7.4)
# AND THE RUN AS A WHOLE: ~0.10 kg for tap plus stop, against 0.51 kg with the noise bells
# in the solve. Generous at both ends -- the tap's 0.6 s and the stop's 0.7 s of 138 N m
# are real spending, and the ceiling is what would catch a hull that went back to burning
# through a hold.
CHECK sum(r["rates"][0] * r["dt"] for r in drainlog) > 0.03
CHECK sum(r["rates"][0] * r["dt"] for r in drainlog) < 0.30
