# --drain-log measured its window BETWEEN PRINTS, so the interval it divided
# by was however much SIM time the warp covered in half a second of wall time.
# At 10x that was 5.2s of sim per row, so the same engine at the same throttle
# read ~10.5 kg/s at 10x and 105.4 kg/s at 1x, and dt= (which the row prints)
# was the print gap rather than the interval the rate described (#376).
#
# The sampler now runs on every physics tick and accumulates, so a row covers
# the SIM time since the previous row and the rows tile the timeline. Two
# consequences, both pinned here:
#   * the rate is warp-invariant -- 105.44 kg/s at 10x, the figure
#     38-asparagus-flight pins at 1x;
#   * nothing goes unmeasured. Printing only the last fixed 0.5s window before
#     each print covered 13% of the sim at 10x and read a real burn as 0.000;
#     dt= now equals the gap between rows, which is what makes that visible.
NAME drain-rate-warp-invariant
CLAIM --drain-log's kg/s figures do not depend on the warp factor, and consecutive rows account for all the sim time between them.
KIND golden
ARGS --timeout 14 --time-accel 10 --startship heavy_asp,res/ships/heavy_asp.json,Kerbin,pad
ARGS --drain-log --sim-press 500,12000,T
EXPECT [drainlog]
FORBID error:
FORBID FAILED
# dt= is the sim time the row covers, so from the second row on it is exactly
# the gap between rows: every sim second is counted once. The old code printed
# dt=0.667 against a 5.167s gap. 0.01s of slack is the rows' 3-decimal rounding.
CHECK all(abs(b["dt"] - (b["t"] - a["t"])) < 0.01 for a, b in zip(drainlog, drainlog[1:]))
# The first stage's two feeding groups at the rated flow 38 pins at 1x. A
# warp-scaled window divides the same spend by ~10x the interval and lands near
# 10.5, which is what this case is for.
CHECK len([r for r in drainlog if abs(r["thrust"] - 927872.0) < 0.01 * 927872.0]) >= 4
CHECK all(len([v for v in r["rates"].values() if v > 1.0]) == 2 for r in drainlog if abs(r["thrust"] - 927872.0) < 0.01 * 927872.0)
CHECK all(abs(v - 105.44) < 0.05 * 105.44 for r in [r for r in drainlog if abs(r["thrust"] - 927872.0) < 0.01 * 927872.0] for v in r["rates"].values() if v > 1.0)
