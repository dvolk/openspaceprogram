NAME jet-flight-envelope
CLAIM The shipped jet pays air for the union of its parts (3.4 m2 nose-on, not a 30 m2 balloon), the lift it makes now owes induced drag, and a held stick tumbles an airframe that has no pitch stability.
KIND golden
ARGS --time-accel 1 --startship jet,res/ships/jet.json,Kerbin,flying-slow
ARGS --timeout 14 --drag-log --mass-log
ARGS --sim-press 1000,3000,R
ARGS --sim-press 1500,6000,T
ARGS --sim-press 3000,3000,W
EXPECT [drag]
EXPECT [ctrl]
CHECK len(drag) >= 10
CHECK all(d.get("aoa") is not None and abs(d["aoa"]) < 1.0 for d in drag[:3])
# RE-BASELINED 2026_10_28 for #463: 28-33 m2 -> 3.4 m2, exactly the collapse the
# ticket asked for. The nose-on rows used to pay for a convex skin stretched
# wingtip to wingtip and up the fuselage; the union charges the pod, the two
# plates edge-on and the fins, and no air that is not there.
CHECK 3.0 < min(d.get("a", 0.0) for d in drag[:3]) < 4.0
# Turned broadside the same airframe presents ~3x the area (10.1 m2 at AoA ~91
# deg): the area tracks the SHAPE, not a bubble around it. Reproduced to 0.01 m2
# across runs, unlike everything measured inside the tumble below (#472).
CHECK max(d.get("a", 0.0) for d in drag) > 2.0 * min(d.get("a", 0.0) for d in drag)
# |L| / q, lift capability in area units: it used to sample 13.5 and now reaches
# the catalog ceiling (2 wings x 8 m2 at CLmax 2.1 = 33 m2-equivalent). The lift
# doubled because the balloon's 9x-inflated drag used to bleed the airframe before
# it could ever reach a useful AoA. The band is deliberately loose: this peak lives
# inside the tumble, and a run-to-run spread of 32..34 (jet) / 24..34 (glider) is
# what #472 gives us. 4x the lift_area drops it under the floor; 4x the silhouette
# pushes L/F out of its band below.
CHECK 10.0 < max(d["L"] / (0.5 * d["rho"] * d["v"] * d["v"]) for d in drag if d.get("L") and d["v"] > 1.0) < 60.0
# #462's coupling, and the pin that says the induced term is not decoration: the
# substeps that lift (|L| / q over 1, comfortably above the 3-decimal print) pay
# induced drag; the post-stall rows print Induced=0 with their |L| = 0. Charge the
# term unconditionally, or drop it, and one of these two fails.
CHECK any(d.get("induced", 0.0) > 0.0 for d in drag)
CHECK all(d.get("induced", 0.0) > 0.0 for d in drag if d.get("L", 0.0) / max(0.5 * d["rho"] * d["v"] * d["v"], 1.0) > 1.0)
CHECK all(d.get("induced", 0.0) == 0.0 for d in drag if d.get("L", 0.0) == 0.0)
# L/D 0.91 (was 0.42): the drag fell ~9x and the lift did not. Still nowhere near
# a sailplane's 30-50 (#455), because these wings are thick plates at AR 2.
CHECK 0.85 < max(d["L"] / d["F"] for d in drag if d.get("L") and d.get("F")) < 0.95
# DROPPED on purpose (was 0.6..1.0 g): "how much of its weight the wings carry"
# now peaks inside the tumble, and the tumble is not reproducible run to run --
# 0.28 g and 0.96 g for two runs of this case, because the tick clamp discards
# accumulated time when frames are slow (#472). Re-pin it with #472's fixed step
# budget, and with #454's static margin giving it a steady state to measure.
# PINNING A BUG, NOT CELEBRATING ONE: |AoA| reaches 143-178 deg -- holding W for
# 3 s tumbles the airframe end over end, |L| collapsing to 0 in the droop and
# recovering on the far side. The balloon's imaginary 30 m2 at the centre of
# pressure was the only pitch damping this ship had; #463 removed it and the
# missing static margin is now visible. When #454 lands, THIS CHECK IS EXPECTED
# TO FAIL: re-baseline it to a sane envelope in that commit.
CHECK max(abs(d["aoa"]) for d in drag if d["aoa"] is not None) > 90.0
CHECK any(d.get("L", 0.0) == 0.0 for d in drag)
# The surfaces earn their keep. W is held for 3 s and the elevons reach their
# max_deflection (0.35 rad = 20.1 deg printed); every row carries the t= of the
# [drag] sample it printed under. Nothing parsed [ctrl] before #458, so no case
# could see a control surface move at all.
CHECK all(d["t"] is not None for d in ctrl)
CHECK any(d["axis"] == "pitch" and abs(d["deg"]) > 15.0 for d in ctrl)
