NAME pointing-alive-at-rcs-zero
CLAIM With the RCS authority dial at 0 the translation keys are off, yet the same ring still turns the hull at its full rated authority (#1067, #595).
KIND invariant
# flight/677 established that a ring-only hull can be stopped from spinning: its bells
# are actuators in the same allocator as drums, gimbals and fins, and
# kill-rot spends 138 N m of the ring's pitch authority to do it. This case is that
# case with --rcs-frac 0 bolted on, which is the boundary #1067 has to hold: the
# dial belongs to the TRANSLATION demand, and pointing must not feel it. The
# wrong implementation -- scaling the nozzle rating instead of the demand, which
# every [rcs] newton on rcs_box_pair fails to notice -- lands here: half the
# rating is half the torque, tau_spent falls to a fraction of 138 N m, the spin
# never comes down, and the pins below go red.
# rcs_test because it is the ring-only hull (#595's fixture): the tap (S, 600 ms)
# leaves ~0.8 rad/s, X is HELD from 6 s as the player would hold it, and the
# vacuum bed means nothing else damps the spin. --no-paint because nothing here
# is a picture (#666 proved the numbers survive it).
ARGS --time-accel 1 --startship rcs_test,res/ships/rcs_test.json,Kerbin,inertial-orbit
ARGS --slew-log --fuel-log --no-paint --rcs-frac 0
ARGS --sim-press 3000,600,S,6000,3000,X
ARGS --timeout 12
LIMIT 40
EXPECT [slew]
EXPECT RCS: translation limited to 0% of what the ring can do that way
FORBID error:
FORBID FAILED
CHECK len(slew) >= 15
# Two shapes now share [slew]: the HOLD rows (killrot, while X is held from 6 s) and the
# TAP rows (mode=stick, while S is held at 3 s). #1130 asked for the second one -- with
# only laws logging, a key press of your own left no row anywhere, so the spin-up these
# pins rely on was inferable but never measured.
CHECK all(s["mode"] == "killrot" for s in slew if s["t"] > 6.0)
CHECK sum(1 for s in slew if s["mode"] == "stick") >= 4
# THE RING IS SPENT ON POINTING, at its own ceiling (a --steering-log run on rcs_test
# prices it at 276/138/138 N m, R/P/Y). The whole point of the case is that this number
# does not move when the keys' dial goes to 0. tau_spent is exactly 138 -- the pitch
# rating -- in every actuated row, so the floor is 138 minus a twelfth and the ceiling
# only holds while the ask stays on pitch (roll is worth 276).
CHECK max(s["tau_spent"] for s in slew) > 120
CHECK all(s["tau_spent"] <= 145.0 for s in slew)
# #1130's question, answered where it was asked: does the TRANSLATION dial reach a
# POINTING tap? The tap rows say no -- with --rcs-frac 0 the stick still asks for the
# ring's whole 138 N m and the ring still spends it, ask and spent identical to the last
# printed digit in every run taken at --rcs-frac 1.0 / 0.65 / 0.35 / 0.0. Both columns
# print at %.0f, so "the same" is only assertable to the print quantum: at a quarter and
# three quarters of the pointing rating the two columns of ONE row come out 35/34 and
# 104/103 from rounding alone. Hence 2 N m of slack, not 1.
CHECK all(s["tau_spent"] > 130.0 for s in slew if s["mode"] == "stick")
CHECK all(abs(s["tau_ask"] - s["tau_spent"]) < 2.0 for s in slew if s["mode"] == "stick")
# AND THE RAMP BELONGS TO THE HARDWARE. 138 N m over this hull's 86 kg m^2 about pitch is
# 1.605 rad/s^2 -- flight/595's prograde rows print that Ieff and call the quotient
# alpha=1.606; neither the killrot rows nor the tap rows this case reads carry an Ieff
# column, so the figure is quoted from there rather than from here. The slope between the
# first and last tap row is 1.6002..1.6039 in the fourteen runs taken for this case (six
# alone, eight in concurrent fours), so the tap accelerates the hull at whatever the ring
# is worth no matter where the translation dial sits. What DOES move is when the release
# lands: the tap rows end at t=3.550..3.667 and leave 0.80..0.99 rad/s, because --sim-press
# without --sim-steps is wall-clock timed (#138, #871). That spread is the 14-17 % #1130
# read as the dial biting, and it is why the slope rather than the endpoint is pinnable.
# len() guards the lambda: with a single row the slope is a division by zero.
CHECK (lambda st: len(st) >= 2 and 1.58 < (st[-1]["wnorm"] - st[0]["wnorm"]) / (st[-1]["t"] - st[0]["t"]) < 1.62)([s for s in slew if s["mode"] == "stick"])
# AND THE SPIN GOES AWAY with the keys' dial at zero.
CHECK max(s["wnorm"] for s in slew) > 0.25
CHECK min(s["wnorm"] for s in slew) < 0.01
CHECK last(slew)["wnorm"] < 0.01
# HYDRAZINE PAYS for the HOLD: no translation key is ever pressed, so every gram
# that left the tank went into attitude. A dial that reached the ratings would
# still burn, so this one is the company the torque pin keeps. Measured 78.5 ->
# 78.4..78.2 kg over three runs; the keys' dial is at 0, so the ring points with
# every bell it has. Like 677, the drop is the hold rather than the stop -- the tank
# keeps moving through rows that print tau_ask=0 tau_spent=0, since those columns
# sample the last actuated substep -- and [fuel] prints one decimal, so the floor
# only says the tank moved at all (#679 asks how much of a hold is dither).
CHECK first(fuel)["groups"][0]["N2H4"][0] - last(fuel)["groups"][0]["N2H4"][0] > 0.0
CHECK first(fuel)["groups"][0]["N2H4"][0] - last(fuel)["groups"][0]["N2H4"][0] < 1.5
