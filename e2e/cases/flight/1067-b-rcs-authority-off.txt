NAME rcs-authority-off
CLAIM Dialed to 0, the RCS translation keys fire nothing at all (#1067) -- the handle a heavy hull needed to stop shoving its neighbours.
KIND invariant
# The bottom of the Systems dial is not "very little thrust", it is the same
# early-out the hull takes when it has no ring: rcsPlan leaves the demand at
# zero, so applyRcsForce has nothing to spend and the [rcs] line never prints.
# The ABSENCE needs a partner, though: that line is gated on --drag-log, so
# "no [rcs] rows" is also what a run with the log door shut looks like, and a
# zero that quietly kept the hydrazine ticking would slip through it too. The
# fuel pin is the positive half -- the tank must not move at all while the key
# is held. (flight/1067-c pins the other side: at 0 the ring still TURNING is a
# different door, and this one never closes it.)
# What 0 does NOT close is the ring's ATTITUDE half, which stays on its own
# switch (#595): pointing the hull and pushing it are different doors, and this
# dial only ever had the second one in hand.
ARGS --time-accel 1 --sim-steps 480 --startship rcs_box_pair,res/ships/rcs_box_pair.json,Kerbin,inertial-orbit --att-log --drag-log --fuel-log --rcs-frac 0 --sim-press 2000,3000,N
EXPECT RCS: thrust limited to 0% of the ring
FORBID [rcs]
CHECK len(att) >= 6
CHECK max(a["wnorm"] for a in att) < 0.02
# THE TANK DOES NOT MOVE. The key is held from 2 s to 5 s and every fuel row
# straddles it; a dialed-to-zero ring that still drew propellant would show a
# fall here even with the [rcs] line suppressed.
CHECK len(fuel) >= 2
CHECK first(fuel)["groups"][0]["N2H4"][0] == last(fuel)["groups"][0]["N2H4"][0]
