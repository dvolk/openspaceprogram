# A thruster ring has always pushed a hull sideways, and since #595 it can TURN one:
# each bell is an actuator row in the same allocator as the drums, the gimbals and the
# fins. What #677 found is that one of the laws never got told. Vehicle::killRotDemand
# asks "is there any authority at all?" before stating its demand, and it asked over
# three actuators -- wheels, surfaces, gimbals -- so a hull with nothing but a thruster
# ring and a tank failed the test, asked for 0 N m, and coasted at whatever rate a stick
# tap left it. The mode was latched, the Autopilot window said Kill rotation, [slew]
# printed mode=killrot, and the hull spun forever:
#
#   [slew] t=4.050 mode=killrot |w|=0.3148 rad/s  tau_ask=0   tau_spent=0
#   ...    t=11.567 mode=killrot |w|=0.3148 rad/s  tau_ask=0   tau_spent=0
#
# (those rows are the pod hull of the day; #1120 replaced that fixture, and the same tap
# on the ring this case now flies leaves 0.83-0.91 rad/s instead of 0.31. Both quoted rows
# predate the stick= column that every [slew] row carries now, #1130 and #1137.)
#
# while the SAME ring spent 138 N m answering the stick one row earlier in the same
# substep, and flight/595-rcs-turns-a-wheel-less-hull holds prograde on the very same
# hull -- slewDemand asks per axis through attitudeTorqueAbout, which has included the
# ring all along.
#
# The S tap (600 ms) is the disturbance and X is HELD from 6.0 s, which is what the
# player does -- X is an override, not a latch, and a latched law's [slew] rows only
# exist while the key is held, so the killrot rows are the hold. The tap has rows of its
# own now (mode=stick, #1130), so the mode filters below are windows, not the whole log.
# --no-paint because nothing here is a picture and #666 proved the numbers do not move
# when the paint pass goes away.
NAME kill-rot-stops-a-ring-only-hull
CLAIM Holding kill-rot on a hull whose only steering is its thruster ring asks for torque, spends hydrazine, and puts the spin down.
KIND invariant
ARGS --time-accel 1 --startship rcs_test,res/ships/rcs_test.json,Kerbin,inertial-orbit
ARGS --slew-log --drain-log --no-paint
ARGS --sim-press 3000,600,S,6000,3000,X
ARGS --timeout 12
LIMIT 40
EXPECT [slew]
EXPECT [drainlog]
FORBID error:
FORBID FAILED
# The hold is 3 s of kill-rot and nothing else is latched, so every row is this law.
CHECK len(slew) >= 15
# Every row used to be this law; since #1130 made the manual stick log, the 3 s TAP also
# prints rows (mode=stick) and they sit outside the hold window. The window is what the
# claim is about, so the filter is the window.
CHECK all(s["mode"] == "killrot" for s in slew if s["t"] > 6.0)
CHECK sum(1 for s in slew if s["mode"] == "stick") >= 4
# The line in this case's preamble -- "the SAME ring spent 138 N m answering the stick" --
# used to be something you had to take on faith because no stick row was ever printed.
# Now it is: the tap rows print stick=[+0.00 -1.00 +0.00] with tau_ask=138 tau_spent=138
# in all of them, and flight/1067-c-pointing-alive-at-zero pins the ramp they
# produce. Envelope rather than equality, as for the hold rows above: 138 is this fixture's
# golden and both columns print at %.0f, so this case should go red for a law that stopped
# asking, not for a rounding boundary. --rcs-att-frac 0.5 spends 69 and reddens it either way.
CHECK all(s["tau_ask"] > 130.0 and s["tau_spent"] > 130.0 for s in slew if s["mode"] == "stick")
# THE LAW ASKS. tau_ask is the summed demand for the last actuated substep: I*(-w)/h
# on a ~0.9 rad/s spin is fourteen thousand N m, which is the hull saying "stop", not a
# number anyone should read as a thrust. Before #677's fix this is 0 in every row, so
# the pin below is the ticket.
CHECK max(s["tau_ask"] for s in slew) > 1000
# THE HARDWARE ANSWERS, at the ring's own ceiling: rcs_test is four rcs_box units bolted
# to the skin of a 1 m mono tank, and a --steering-log run prices that ring at 276/138/138
# N m (R/P/Y). tau_spent sits on the 138 N m pitch rating while tau_ask towers above it --
# the allocator spending the ring as hard as it can, never past what it is worth. The
# ceiling is this tight only while the ask stays on pitch: the roll rating is 276, so an
# off-axis demand would need a wider cap rather than a broken ring.
CHECK max(s["tau_spent"] for s in slew) > 120
CHECK all(s["tau_spent"] <= 145.0 for s in slew)
# AND THE SPIN GOES AWAY. The tap leaves ~1.05 rad/s (0.83-0.91 before #1152 took the hull's
# collision skin out of Ieff) -- the spread is where a wall-clock press release lands (#138,
# #871), not the ring -- and that spin-up does not come from kill-rot at all -- which is how
# #677 stayed visible: the broken build reached the same rate and then kept it. ~0.6 s of
# hold takes it to nothing, at 138 N m on Ieff 66 kg m^2 = 2.1 rad/s^2, which is the rate
# 595 prints (and pins).
CHECK max(s["wnorm"] for s in slew) > 0.25
CHECK min(s["wnorm"] for s in slew) < 0.01
CHECK last(slew)["wnorm"] < 0.01
# It STAYS DOWN while the key is still held -- the last row is t=9.017 and X comes up at
# 9.0, so "after the key comes up" is not something these rows can show. In this vacuum
# drift bed nothing else damps a spin, so a hull that had merely been nudged rather than
# stopped would still be turning in the tail rows.
CHECK all(s["wnorm"] < 0.02 for s in slew if s["t"] > 8.0)
# HYDRAZINE PAYS for the MANEUVER. No translation key (N/I/L/J/K/U) is ever pressed, so
# every gram that left the tank went into attitude: 0.056 kg/s while 138 N m puts 0.88
# rad/s down, and 0.095-0.10 on the drain integral over the run -- an upper bound on the
# kilograms, since a row's rate divides by the seconds it flowed and dt= is the whole
# window (flight/679 spells it out). It is read off --drain-log rather than the [fuel]
# print because [fuel] prints one decimal and 0.1 kg is smaller than one step of it --
# which is also why this case's fuel pin used to be weaker than it looked. Mind what the
# spend is NOT: it belongs to the tap and the stop, and the tank is flat (0.000 kg/s) for
# the rest of the hold. It used to keep falling at 0.08 kg/s for as long as X stayed down,
# and that was #679 -- four of the twenty bells lever roundoff, 3e-10..3e-9 N m against the
# ring's 69, and a cost-blind solve was
# loading them to full thrust -- which flight/679-holding-a-stopped-ring-hull-does-not-drink
# now pins. Note that those [slew] rows print tau_ask=0 tau_spent=0 throughout: the columns
# record the last ACTUATED substep, not a sum over the row (see slew_log), so [slew] was
# never the instrument that could see #679 -- only the drain columns can. Hence the
# ceiling here: 0.095-0.10 post-fix, 0.22-0.40 on a build that puts the noise bells back.
CHECK max(r["rates"][0] for r in drainlog) > 0.03
CHECK sum(r["rates"][0] * r["dt"] for r in drainlog) < 0.15
