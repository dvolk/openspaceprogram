NAME tvc-slew-prograde
CLAIM The autopilot flies a wheel-less ship on gimballed thrust: a prograde hold chases back a stick disturbance.
KIND invariant
# tvc_test has no reaction wheel: pre-#417 the slew law never ran on it
# (applyRotationForce early-returned), so SAS was silent and a stick tap
# left the nose drifting forever. Now the law budgets authority from the
# ARMED engines (throttle from T), splits its torque to TVC, and recovers.
# Z toggles prograde hold once (persistent); the S tap (4s) breaks the lock;
# while the burn runs the E-column must spike then hold near zero (a few
# degrees: the target is a velocity vector the TVC force itself bends).
# When T releases at 9s the armed thrust -- and with it the whole TVC
# authority -- drops to zero, and E must drift: the law never pretends to
# steer a ship with no actuators (#401's lesson), and that drift is what
# tells engine-off from engine-on in this log.
#
# The numbers here are SHAPE, not magnitude, because this hull's phase is not
# repeatable. It spawns at 85.0 km -- Kerbin's air top -- and the whole run is
# vacuum (rho 0, Mach dashed, |L| 0 in every [drag] row), so nothing in the air
# law can move it; what moves is where a bang-bang TVC limit cycle happens to be
# when the 8 s throttle ends. --time-accel 1 paces the sim on the wall clock, so
# the run ends at t=12.050-12.167 s (97 or 98 rows) and the residual rate carried
# past cutoff came out -0.1543 rad/s in ten repeats of one binary and -0.0876
# rad/s in a battery run that had 87 other cases for company. Fourteen logs of the
# same ARGS (those ten, both battery runs, and two more after #608): tap peak
# 0.2993-0.4030 rad, hold-window mean 0.0219-0.0264, hold-window peak
# 0.0444-0.0853, E at the last row 0.2814-0.4848. The two pins that used to sit
# INSIDE that spread -- a 0.06
# hold ceiling and a 0.3 final-angle floor -- went
# red on one battery run and green on the next (#605 is this case; #138 is the
# open root cause, the --sim-press windows above are wall-clock timed, so when
# the 8 s throttle really ends moves with the frame cadence -- #472 already fixed
# the other half of it, the tick clamp). So the hold is now pinned by its
# mean plus a ceiling that a hull which never recovered would blow by 3.5x (it
# would still be near the 0.35 rad the tap put there), and the drift is pinned by
# its SHAPE: every post-cutoff row larger than the last, and the total past the
# cutoff at least 0.15 rad -- measured 0.2228-0.4124 in the 9.4 s window.
ARGS --time-accel 1 --startship tvc_test,res/ships/tvc_test.json,Kerbin,rot-orbit
ARGS --att-log --slew-log --orbit-interval 0.3
ARGS --sim-press 1000,8000,T
ARGS --sim-press 1000,0,Z
ARGS --sim-press 4000,400,S
ARGS --timeout 12
LIMIT 90
EXPECT [attlog]
EXPECT [slew]
FORBID error:
CHECK len(att) >= 10
CHECK len(slew) >= 10
CHECK max(s["E"] for s in slew if 4.3 < s["t"] < 5.5) > 0.02
# THE HOLD: SAS pulls the nose back and keeps it there. Measured mean 0.0230-0.0264
# rad and peak 0.0463-0.0800 over the ten runs above, so the mean is the tight pin
# and the peak is the loose one -- a hull that never recovered would still be near
# the 0.35 rad the tap put there, 3.5x over this ceiling.
CHECK max(s["E"] for s in slew if 6.0 < s["t"] < 8.8) < 0.10
CHECK sum(s["E"] for s in slew if 6.0 < s["t"] < 8.8) / len([s for s in slew if 6.0 < s["t"] < 8.8]) < 0.04
# ENGINE OFF, NO STEERING: from 9.4 s (clear of the hold's last swing) every row is
# bigger than the last -- the law does not arrest a wheel-less hull with no armed
# engine -- and the total past the cutoff is 0.2228-0.4124 rad in those runs. The
# old pin here was the final angle alone (> 0.3), which the spread straddles.
CHECK all(a["E"] < b["E"] for a in slew for b in slew if 9.4 < a["t"] < b["t"])
CHECK last(slew)["E"] - min(s["E"] for s in slew if s["t"] > 9.4) > 0.15
# NO THRUST, BUT NOT NO ACTUATORS either. alpha= is what the armed engines can lever
# THIS TICK, so a released throttle takes it to zero -- and alpha_full= (#608) is the
# same axis with the ignited stage at FULL throttle, which does not follow the lever:
# 2.230-2.284 rad/s^2 while the burn runs (the mass and the COM both move under it) and
# flat 2.227 once the throttle is shut. That pair is the distinction this case's drift
# has always leaned on and could not state: the hull went quiet because it stopped
# burning, not because it has no steering. The 1.0 floor is a little under half the
# measured rating and would fail on a hull with gimbal_max 0 or no engine lit.
# The window is the drift pins' 9.4 pushed 0.2 s later, which is the only slack this
# case can promise: the press releases T at wall-clock 9 s, and in three logs the last
# live row came at 9.000-9.067 and the first zero row at 9.100-9.183 -- so 9.6 leaves
# ~0.4 s, and every pin above already assumes cutoff before 9.4.
CHECK all(s["alpha"] < 1e-3 for s in slew if s["t"] > 9.6)
CHECK all(s["alpha_full"] > 1.0 for s in slew if s["t"] > 9.6)
CHECK any(s["alpha"] > 1.0 for s in slew if 6.0 < s["t"] < 8.8)
# And while the lever is FULL -- which it is through the hold window, T having been held
# since 1 s -- the two columns are the same number (2.230/2.230 at the same row). The
# rating is not a second model of the gimbal; it is this one with the lever pushed in.
CHECK all(abs(s["alpha"] - s["alpha_full"]) < 0.05 for s in slew if 6.0 < s["t"] < 8.8)
# WHAT THE ASK BOUGHT (#599). alpha= is a rating; tau_ask/tau_spent are what the last
# actuated substep COST -- the demand the law summed, and the torque measured off the
# deflected nozzles (this hull has no wheels and no air, so tau_spent IS the gimbals).
# The law sizes its demand off the RATE error (I*dW/h), so at the tap it asks up to 393 kN
# m of an engine that can lever ~3 kN m: 131x on one row, 14 rows over 50x. That is what a
# hull that reads capable on screen looks like once there is a spent number at all.
CHECK any(s["tau_ask"] > 50 * s["tau_spent"] for s in slew if 4.3 < s["t"] < 5.5)
# Never more than the disk, stated as the rating rather than as a magic threshold:
# alpha*Ieff is the N m the armed thrust could lever about the steered axis THIS tick
# (2950-2993 in the tap window, 2794-2919 in the hold -- the lever grows as the fuel comes
# down), and the measured spend stays inside it, worst live ratio 0.999 over two runs.
CHECK all(s["tau_spent"] <= 1.05 * s["alpha"] * s["Ieff"] + 1 for s in slew if s["t"] > 1.0)
# And it is not idling: wherever there is authority there is a measured torque (min 298 N
# m across both runs).
CHECK all(s["tau_spent"] > 0 for s in slew if s["alpha"] > 1.0)
# THE PART A RATING CANNOT SHOW: the spend is a FRACTION of its own rating on some rows,
# because a ring of nozzles has to TRAVEL to its aim at gimbal_rate and swings back
# through centre on every reversal of the limit cycle. Worst live ratio 0.101 in both runs
# (the first rows of the burn, the ring still centred) and 0.201 inside the hold window.
# A routed share of the TVC budget would have read the rating every one of those rows.
CHECK any(s["tau_spent"] < 0.5 * s["alpha"] * s["Ieff"] for s in slew if 1.0 < s["t"] < 8.9 and s["alpha"] > 1.0)
# There is deliberately no tau_spent <= tau_ask pin, even though the allocator itself
# never over-delivers on a line: a gimbal KEEPS its aim between substeps, so a hull that
# has come round -- the law asking almost nothing -- is still being turned by the nozzle
# the last substep left deflected. Measured 2.95x the ask on two rows.
# And with the throttle shut the LAW goes quiet too: alpha 0 makes slewDemand ask for
# nothing AND takes away the thrust the nozzles push with, so BOTH columns read zero. That
# is why the drift above is a hull with nothing to spend rather than a law fighting and
# losing.
CHECK all(s["tau_ask"] == 0 and s["tau_spent"] == 0 for s in slew if s["t"] > 9.6)
# SLEW_RE drops a row whose columns it cannot match ([-\d.]+ will not take a nan), which
# would weaken every pin above in silence. The row count is the tripwire.
CHECK out.count("[slew] t=") == len(slew)
CHECK all(a["wnorm"] == a["wnorm"] and a["wnorm"] < 1e4 for a in att)
