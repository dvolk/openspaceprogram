# A ring of thrusters pushes a ship sideways and has always been able to. What it could
# not do is TURN one: #428 spends the ring against the translation keys at the top of the
# mixer and never hands any of it to the attitude path, so a hull with no wheels and no
# armed engine has alpha 0.000 -- no turning authority at all -- while a pod full of bells
# fires on the same ship (the ticket's repro, one RCS pod and a mono tank on a prograde
# hold: E crept up 0.0188 rad in 6.8 s and nothing in the game could close it).
#
# #595 makes each bell an actuator row in the same allocator as the drums, the gimbals and
# the fins, priced at arm x thrust (a bell's LEVERAGE, not its newtons) and one-way (gas
# goes out one way, so a ring fitted the wrong way round credits nothing about that axis).
# Translation still eats first: rcsPlan() runs before the mixer, and the rows carry only
# the fraction the keys left. That order is the ticket's "a PRIORITY, not a sum", and
# tests/test_authority.cpp pins it in the body frame; this case is the same fact flying.
#
# rcs_test is four rcs_box units bolted to the skin of a 1 m mono tank (#1120 took out the
# round pod this hull used to be), so a --steering-log run on it prices the ring at
# 276/138/138 N m (R/P/Y) -- it can roll as well as pitch and yaw -- and the prograde law
# steers against alpha 1.60 rad/s^2 on Ieff 86 kg m^2. Those are the numbers the rows
# print: a bell ring is a weak actuator next to a drum, and the case says so rather than
# dressing it up.
NAME rcs-turns-a-wheel-less-hull
CLAIM With no wheels and no engine, a thruster ring holds prograde: it has authority, spends hydrazine to use it, and closes a stick disturbance.
KIND invariant
# The S tap (600 ms) is the disturbance; prograde hold is on from the start. Before #595
# the tap spent nothing -- the ring was not an actuator, so tau_spent stayed 0 and w_slew
# stayed at its 0.003 rad/s floor however hard the key was held. The tap is now visible in
# the rows themselves twice over: while S is down the prograde rows carry
# stick=[0, -1, 0] (#1137), and on a hull with nothing latched a tap prints rows of its own
# (#1130). So the two middle pins are the whole claim: the nose MOVES, and then the ring
# BRAKES it and closes the error again. Measured over two runs of these ARGS: tap-window
# w_slew down to -0.86..-0.96 rad/s, E peak 0.54-0.58 rad at t=4.2-4.3, error back under
# 0.01 rad by t=5.3-5.4, and 0.14 kg of hydrazine gone with no translation key ever
# pressed -- 0.7 kg before #679 pulled the no-leverage bells out of the attitude solve.
ARGS --time-accel 1 --startship rcs_test,res/ships/rcs_test.json,Kerbin,inertial-orbit
ARGS --autopilot prograde --slew-log --drain-log --orbit-interval 0.5
ARGS --sim-press 3000,600,S
ARGS --timeout 12
LIMIT 40
EXPECT [slew]
EXPECT [drainlog]
FORBID error:
FORBID FAILED
CHECK len(slew) >= 40
# THE AUTHORITY EXISTS. alpha is the pointing budget the laws steer against, and it used to
# read 0.000 on this hull for as long as it coasted. It is now 1.60 rad/s^2 in every row
# (1.602-1.631 across runs), whether or not anything is being asked for -- a rating, not a
# spend. The floor is three quarters of that rating: #595's bug was alpha 0, and a ring
# that quietly lost half its leverage is still this case's business.
CHECK all(s["alpha_full"] > 1.2 for s in slew)
CHECK all(s["alpha"] > 1.2 for s in slew)
# THE RING MOVES THE HULL: during the hold the only thing acting is thruster gas, and the
# rate it buys is what the rows say it can (138 N m on Ieff 86 is 1.6 rad/s^2, so 600 ms
# of full bells is ~0.9 rad/s; measured -0.86..-0.96 in the window). -0.5 keeps room for
# the row grid itself shifting ~0.05 s between runs, which is #1054's shape.
CHECK min(s["w_slew"] for s in slew if 3.0 < s["t"] < 3.7) < -0.5
CHECK max(s["tau_spent"] for s in slew if 3.0 < s["t"] < 3.7) > 100
# AND THE SAME RING PUTS IT BACK: the error peaks near 0.55 rad and is gone by the end. A
# hull that could not turn would still be sitting at its tap angle, so the tail window is
# the pin that a runaway cannot pass.
CHECK max(s["E"] for s in slew) > 0.30
CHECK max(s["E"] for s in slew if s["t"] > 7.0) < 0.01
CHECK last(slew)["E"] < 0.005
# HYDRAZINE PAYS, and only for the turn: no N/I/L/J/K/U key is pressed in this case, so
# every gram that left the tank went into pointing. The rate is the honest one -- flow is
# sized off the FIRING thrust at Isp 220 -- so a hull that faked its own authority would
# show up here as a drain with nothing spent, or the reverse. Read off --drain-log rather
# than the [fuel] print: [fuel] prints one decimal and this turn costs 0.14 kg, which is
# inside one rounding step of nothing. Before #679 the same ARGS spent 0.7 kg and this case
# pinned that figure; four of the twenty bells lever ~1e-5 N m, and a cost-blind solver
# loaded them to full thrust. The hull turns the same either way -- flight/679-... is what
# that waste was and where its pin lives.
CHECK max(r["rates"][0] for r in drainlog) > 0.03
CHECK sum(r["rates"][0] * r["dt"] for r in drainlog) > 0.05
CHECK sum(r["rates"][0] * r["dt"] for r in drainlog) < 0.5
