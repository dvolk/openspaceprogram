NAME glider-flight-envelope
CLAIM The shipped glider pays air for the union of its parts AS MOUNTED (4.4 m2 nose-on, 16.3 m2 in a hard yaw swing, not a 30 m2 balloon), its lift owes induced drag, and since #494 so does its rudder: the three seconds A is held pay 1.7 m2 of induced CdA and the released rows pay 0.0, which is why it now swings 63 deg off the centreline rather than 73 while its pitch stays inside 1 deg of the flow.
KIND golden
ARGS --time-accel 1 --startship glider,res/ships/glider.json,Kerbin,flying-slow
ARGS --sim-steps 840 --drag-log --mass-log
ARGS --sim-press 1000,3000,R
ARGS --sim-press 1500,6000,T
ARGS --sim-press 3000,3000,A
EXPECT [drag]
EXPECT [ctrl]
CHECK len(drag) >= 10
CHECK all(d.get("aoa") is not None and abs(d["aoa"]) < 1.0 for d in drag[:3])
# Same reading as the jet case, on the nose-on rows: 4.35 m2 = the pod disc plus
# the two plates seen edge-on. RE-BASELINED 2026_10_28 twice -- #463's union, then
# the mount offsets it first dropped (which had it at 3.4, charging one part
# instead of a union).
CHECK 4.0 < min(d.get("a", 0.0) for d in drag[:3]) < 5.0
# Turned over, its planforms come into the wind. RE-BASELINED by #483: the worst
# row used to be 26.4 m2 (a 6.1x swing) because the airframe tumbled over again and
# again; it now turns over ONCE, at t=4, and 17.8 m2 is what the 1 s sampling
# catches. The factor is 4.09 on that row, so this sits at 3.0 rather than the 4.0
# it was -- pinning a 2% margin on a row that happens to land mid-swing is asking
# for a false alarm at the next law change. The balloon law showed 1.2x here.
CHECK max(d.get("a", 0.0) for d in drag) > 3.0 * min(d.get("a", 0.0) for d in drag)
# On the clean rows the force printed IS the law printed: |F| / (q * Cd * A) =
# --drag-cd's 1.2 default. The knob-sensitive pin: --drag-cd 0.2 or 8 fails it
# while the shape pins above still pass.
CHECK 1.15 < max(d["F"] / (0.5 * d["rho"] * d["v"] * d["v"] * d["cd"] * d["a"]) for d in drag[:3]) < 1.25
# |L| / q, lift in area units. RE-BASELINED by #503 (it read 8.0..24.8 for two
# months: the peak used to be the row where the airframe lay on its back with both
# planforms in the wind) and again by #494, down to 1.19. This airframe has no
# incidence and no trim, so a symmetric section at 0 deg makes NO lift in this law:
# every newton of lift in this run comes from the yaw swing tipping the wings into the
# flow, and #494 shrank the swing (see the rudder bill below), so the lift went with
# it. The floor is 0.8 so a law that stopped charging lift still fails here. The
# lift-CAPABILITY half of this pin lives in the jet case (32.3), which gets pitched.
CHECK 0.8 < max(d["L"] / (0.5 * d["rho"] * d["v"] * d["v"]) for d in drag if d.get("L") and d["v"] > 1.0) < 10.0
# #462's coupling: the lifting substeps pay induced drag. The post-stall half of the
# pair (|L| = 0 pays nothing) is gone from this case since #503 -- see the excursion
# block below, the airframe no longer reaches the band where the curve is zero -- and
# it stays pinned by test_drag's liftCurve/inducedCd pins.
CHECK any(d.get("induced", 0.0) > 0.0 for d in drag)
CHECK all(d.get("induced", 0.0) > 0.0 for d in drag if d.get("L", 0.0) / max(0.5 * d["rho"] * d["v"] * d["v"], 1.0) > 1.0)
# THE STICK'S OWN BILL (#494), and the cleanest statement of it in the suite: A is
# pressed at t=3 for 3 s, and Induced follows the KEY rather than the lift --
# 0.00, 0.00, 0.00, 1.70, 1.71, 1.72, 0.00, 0.00, 0.00, ... The glider's only lift
# barely changes across those rows, so what is being charged here is the deflection:
# each rudder is 2.0 m2 of control area over a 2.0 m span, so AR 2.0, and at the
# 0.35 rad travel stop #503's droop leaves CL 1.335, giving
# CDI = 1.335^2 / (pi x 0.8 x 2.0) = 0.354 -> 1.2 x 2.0 x 0.354 = 0.851 m2 apiece,
# 1.70 for the pair -- against a 4.35 m2 nose-on silhouette. Nothing on this ship was
# lifting at those rows and nothing paid before #494. Drop the control-surface term
# and the band goes to 0.0; charge it at the SHIP's span instead of the surface's and
# it collapses by the square of the span ratio. The band is 1.6..1.9 rather than
# hugging the 1.70-1.72 measurement: this is a quantity quadratic in the authority the
# surface has, so give the next law change room to move it and let the released-rows
# pin below carry the precision.
CHECK all(1.60 < d["induced"] < 1.90 for d in drag if 4.0 <= d["t"] <= 6.0)
CHECK all(d["induced"] < 0.05 for d in drag if d["t"] >= 7.0)
# IT USED TO GO PAST VERTICAL (#503 ended that). All 14 rows of the 840-tick budget
# now, AoA -0.2, -0.2, -0.1, 0.0, 0.5, -0.7, -0.1, 0.1, -0.1, 0.2, -0.1, 0.1, -0.0,
# 0.0: the airframe never gets more than 0.7 deg off the flow in pitch, on a ship
# with no pitch surface at all. It used to read -0.2, -0.2, -0.1, 115.6, 11.8,
# -10.9, 4.4, ... and before #483, over and under every row to the end of the run
# (14.8, -108.6, 75.2, -36.5, -58.1, -6.6, -96.4, 14.0, 100.1, 48.8).
# The A stick is still held for 3 s and both rudders are still against their travel
# stops; what changed is what a surface AT the stop is worth. The old law billed a
# deflected plate 6.0/rad all the way to 0.35 rad, so full rudder was worth CL 2.1 on
# each of two 2 m2 fins -- and the yaw that drove made the airframe roll through
# vertical, which is how a ship with no elevator ever got 115 deg of angle of attack.
# #503 puts the surface's own stall_angle on the deflection, so the last quarter of
# the throw (0.26 -> 0.35 rad) buys LESS force; the roll never gets started. #494 then
# charges the same deflection 1.70 m2 of induced CdA (the block above), which is a
# second way the stop got cheaper: the rudder's force and its drag now both scale with
# what the surface is actually worth, not with how far the hinge was moved.
CHECK max(abs(d["aoa"]) for d in drag if d["aoa"] is not None) < 5.0
# THE SETTLE, pinned: seven seconds in, every remaining row sits inside 3 deg of the
# flow (worst 0.2). The band used to be 10 deg because the rows it was measuring were
# the tail of a roll through vertical; #503 moved the whole excursion, so the band
# moved with it. Note what it is NOT: no airframe is trimmed here (a symmetric section
# at 0 deg makes no lift in this law, so "settled" means nose-on and descending, not
# gliding). Damping without static margin (#454) is not what did this -- the ship was
# never upset in pitch in the first place.
# AND IT IS STILL PITCH QUIET / YAW ALIVE. Beta reads -62.7, -37.5, -22.6, 45.2,
# -18.6, -26.9, 40.6, 7.0, -44.8, 4.8, 43.4 after the stick: a hard, undamped yaw
# swing that never converges, against 0.7 deg worst in pitch. That is the geometry of
# these terms, not a fluke: at AoA ~ 0 a yaw rate sweeps the wingtips ALONG the nose,
# which changes no angle of attack, and the only yaw surfaces it has are rudders whose
# force is deflection-only -- so nothing damps the yaw except the hull's own weathervane
# moment, which is small on this silhouette. Which is the yaw half of #454/#486, and
# why Beta is pinned as an excursion, never as a settling number.
CHECK all(d["aoa"] is not None and abs(d["aoa"]) < 3.0 for d in drag if d["t"] >= 7.0)
# And the speed it keeps: the tumble used to eat 60% of it (73 m/s by t=14 against a
# 173 m/s start). Since #503 it flies nose-on and costs itself a third: 113.0 m/s worst
# after t=9, and #494's rudder bill leaves 121.8. The floor stays at 90 rather than 110
# because on a 1.2:1 brick (#490) that margin is a brick property, not a law one.
# Re-pin it onto a real airframe when #490 lands one.
CHECK min(d["v"] for d in drag if d["t"] >= 9.0) > 90.0
# THE SWING, pinned at 63 deg (was 72.8 before #494, 94.9 before #503, and 170 when
# the airframe tumbled repeatedly). Both law changes took authority off the stop, so
# this case no longer exercises the silhouette cache's 180-degree wrap -- past +-90 in
# one angle AeroFrame's two angles must wrap together (they share atan2's denominator),
# and when that wrap was missing every row past 90 keyed a different flow's cell, 9%
# off on a hull shaped like this one (tmp/review_20261028). The invariant is still
# pinned as math by test_drag's aeroFrame back-hemisphere block; what this case lost is
# the in-situ version of it, recorded as #504. The floor sits at 45 rather than 60
# because it is the SIZE of the swing that matters here, not the last few degrees: the
# yaw is undamped and will keep swinging wherever the authority leaves it.
CHECK max(abs(d["beta"]) for d in drag if d.get("beta") is not None) > 45.0
# RE-BASELINED by #503 (0.239; it was 0.700 after #486, 0.511 after #483) and by #494
# (0.110). The peak used to live inside the tumble -- a wing held at a huge AoA while
# the airframe spun broadside -- and that peak went with the tumble; what is left is the
# sideslip row, and #494 shrinks the sideslip that makes it. Most of the aero force is
# now hull drag plus the rudder's own bill, and the ratio says so. While the run stepped
# against wall-clock frames this read 0.74, 0.76, 0.79 in three runs, which is why
# #472's --sim-steps matters: the value is only worth pinning because every run prints
# the same rows.
CHECK (lambda ds: 0.08 < max(d["L"] / d["F"] for d in ds) < 0.20)([d for d in drag if d["F"] > 0.0])
# What the airframe is built from: A is held for 3 s and both rudders reach their
# travel limit, and the shipped glider has NO pitch surface at all -- the stick
# cannot ask for nose-up, which is half of why nothing about trim can be tuned on
# it (#454). If a tailplane ever ships, that last line is the one to change.
CHECK all(d["t"] is not None for d in ctrl)
CHECK any(d["axis"] == "yaw" and abs(d["deg"]) > 15.0 for d in ctrl)
CHECK all(d["axis"] == "yaw" for d in ctrl)
