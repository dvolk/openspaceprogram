NAME glider-flight-envelope
CLAIM The shipped glider pays air for the union of its parts AS MOUNTED (4.4 m2 nose-on, 17.3 m2 in a hard yaw swing, not a 30 m2 balloon), its lift owes induced drag, and since #503 a held rudder cannot yaw it past vertical: it swings 73 deg off the centreline while its pitch stays inside 2 deg of the flow.
KIND golden
ARGS --time-accel 1 --startship glider,res/ships/glider.json,Kerbin,flying-slow
ARGS --sim-steps 840 --drag-log --mass-log
ARGS --sim-press 1000,3000,R
ARGS --sim-press 1500,6000,T
ARGS --sim-press 3000,3000,A
EXPECT [drag]
EXPECT [ctrl]
CHECK len(drag) >= 10
CHECK all(d.get("aoa") is not None and abs(d["aoa"]) < 1.0 for d in drag[:3])
# Same reading as the jet case, on the nose-on rows: 4.35 m2 = the pod disc plus
# the two plates seen edge-on. RE-BASELINED 2026_10_28 twice -- #463's union, then
# the mount offsets it first dropped (which had it at 3.4, charging one part
# instead of a union).
CHECK 4.0 < min(d.get("a", 0.0) for d in drag[:3]) < 5.0
# Turned over, its planforms come into the wind. RE-BASELINED by #483: the worst
# row used to be 26.4 m2 (a 6.1x swing) because the airframe tumbled over again and
# again; it now turns over ONCE, at t=4, and 17.8 m2 is what the 1 s sampling
# catches. The factor is 4.09 on that row, so this sits at 3.0 rather than the 4.0
# it was -- pinning a 2% margin on a row that happens to land mid-swing is asking
# for a false alarm at the next law change. The balloon law showed 1.2x here.
CHECK max(d.get("a", 0.0) for d in drag) > 3.0 * min(d.get("a", 0.0) for d in drag)
# On the clean rows the force printed IS the law printed: |F| / (q * Cd * A) =
# --drag-cd's 1.2 default. The knob-sensitive pin: --drag-cd 0.2 or 8 fails it
# while the shape pins above still pass.
CHECK 1.15 < max(d["F"] / (0.5 * d["rho"] * d["v"] * d["v"] * d["cd"] * d["a"]) for d in drag[:3]) < 1.25
# |L| / q, lift in area units. RE-BASELINED by #503 (it read 8.0..24.8 for two
# months): the peak used to be the row where the airframe lay on its back with both
# planforms in the wind, and a held rudder no longer takes it there. 2.7 is what a
# wings-level sideslip at 1 s into the swing buys, and the floor is 2.0 so a law that
# stopped charging lift still fails here. The lift-CAPABILITY half of this pin now
# lives in the jet case (33.6), which still gets pitched hard.
CHECK 2.0 < max(d["L"] / (0.5 * d["rho"] * d["v"] * d["v"]) for d in drag if d.get("L") and d["v"] > 1.0) < 10.0
# #462's coupling: the lifting substeps pay induced drag. The post-stall half of the
# pair (|L| = 0 pays nothing) is gone from this case since #503 -- see the excursion
# block below, the airframe no longer reaches the band where the curve is zero -- and
# it stays pinned by test_drag's liftCurve/inducedCd pins.
CHECK any(d.get("induced", 0.0) > 0.0 for d in drag)
CHECK all(d.get("induced", 0.0) > 0.0 for d in drag if d.get("L", 0.0) / max(0.5 * d["rho"] * d["v"] * d["v"], 1.0) > 1.0)
# IT USED TO GO PAST VERTICAL (#503 ended that). All 14 rows of the 840-tick budget
# now, AoA -0.2, -0.2, -0.1, 0.6, 1.1, -1.6, -0.0, 0.5, -0.3, 0.1, 0.1, -0.5, 0.6,
# -0.6: the airframe never gets more than 1.6 deg off the flow in pitch, on a ship
# with no pitch surface at all. It used to read -0.2, -0.2, -0.1, 115.6, 11.8,
# -10.9, 4.4, ... and before #483, over and under every row to the end of the run
# (14.8, -108.6, 75.2, -36.5, -58.1, -6.6, -96.4, 14.0, 100.1, 48.8).
# The A stick is still held for 3 s and both rudders are still against their travel
# stops; what changed is what a surface AT the stop is worth. The old law billed a
# deflected plate 6.0/rad all the way to 0.35 rad, so full rudder was worth CL 2.1 on
# each of two 2 m2 fins -- and the yaw that drove made the airframe roll through
# vertical, which is how a ship with no elevator ever got 115 deg of angle of attack.
# #503 puts the surface's own stall_angle on the deflection, so the last quarter of
# the throw (0.26 -> 0.35 rad) buys LESS force; the roll never gets started.
CHECK max(abs(d["aoa"]) for d in drag if d["aoa"] is not None) < 5.0
# THE SETTLE, pinned: seven seconds in, every remaining row sits inside 3 deg of the
# flow (worst 0.6). The band used to be 10 deg because the rows it was measuring were
# the tail of a roll through vertical; #503 moved the whole excursion, so the band
# moved with it. Note what it is NOT: no airframe is trimmed here (a symmetric section
# at 0 deg makes no lift in this law, so "settled" means nose-on and descending, not
# gliding). Damping without static margin (#454) is not what did this -- the ship was
# never upset in pitch in the first place.
# AND IT IS STILL PITCH QUIET / YAW ALIVE. Beta reads -72.8, -32.8, -31.2, 55.7,
# -38.6, -10.3, 54.3, -27.1, -36.7, 46.0, 20.6 after the stick: a hard, undamped yaw
# swing that never converges, against 1.6 deg worst in pitch. That is the geometry of
# these terms, not a fluke: at AoA ~ 0 a yaw rate sweeps the wingtips ALONG the nose,
# which changes no angle of attack, and the only yaw surfaces it has are rudders whose
# force is deflection-only -- so nothing damps the yaw except the hull's own weathervane
# moment, which is small on this silhouette. Which is the yaw half of #454/#486, and
# why Beta is pinned as an excursion, never as a settling number.
CHECK all(d["aoa"] is not None and abs(d["aoa"]) < 3.0 for d in drag if d["t"] >= 7.0)
# And the speed it keeps: the tumble used to eat 60% of it (73 m/s by t=14 against a
# 173 m/s start). Since #503 it flies nose-on and costs itself a third: 113.0 m/s worst
# after t=9. The floor stays at 90 rather than 110 because on a 1.2:1 brick (#490) that
# margin is a brick property, not a law one. Re-pin it onto a real airframe when #490
# lands one.
CHECK min(d["v"] for d in drag if d["t"] >= 9.0) > 90.0
# THE SWING, pinned at 73 deg (was 94.9, and 170 when the airframe tumbled
# repeatedly). RE-BASELINED by #503: with a stalled rudder at full throw the yaw
# tops out short of the back hemisphere, so this case no longer exercises the
# silhouette cache's 180-degree wrap -- past +-90 in one angle AeroFrame's two angles
# must wrap together (they share atan2's denominator), and when that wrap was missing
# every row past 90 keyed a different flow's cell, 9% off on a hull shaped like this
# one (tmp/review_20261028). The invariant is still pinned as math by test_drag's
# aeroFrame back-hemisphere block; what this case lost is the in-situ version of it.
# Bring it back by re-tuning this airframe's surfaces (#490) rather than by loosening
# the law.
CHECK max(abs(d["beta"]) for d in drag if d.get("beta") is not None) > 60.0
# RE-BASELINED by #503 (0.239; it was 0.700 after #486, 0.511 after #483). The peak
# used to live inside the tumble -- a wing held at a huge AoA while the airframe spun
# broadside -- and that peak is gone with the tumble. What is left is the sideslip
# row: the wings still make lift, most of the aero force is now hull drag, and the
# ratio says so. While the run stepped against wall-clock frames this read 0.74, 0.76,
# 0.79 in three runs, which is why #472's --sim-steps matters: the value is only worth
# pinning because every run prints the same rows.
CHECK (lambda ds: 0.20 < max(d["L"] / d["F"] for d in ds) < 0.35)([d for d in drag if d["F"] > 0.0])
# What the airframe is built from: A is held for 3 s and both rudders reach their
# travel limit, and the shipped glider has NO pitch surface at all -- the stick
# cannot ask for nose-up, which is half of why nothing about trim can be tuned on
# it (#454). If a tailplane ever ships, that last line is the one to change.
CHECK all(d["t"] is not None for d in ctrl)
CHECK any(d["axis"] == "yaw" and abs(d["deg"]) > 15.0 for d in ctrl)
CHECK all(d["axis"] == "yaw" for d in ctrl)
