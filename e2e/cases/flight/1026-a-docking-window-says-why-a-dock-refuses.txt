# The Docking window's first job (#1026): say WHY a dock did not happen. Before it, a
# pair that failed to mate was just two ships that did not mate -- the gate in
# Game::updateDocking returned silently, six different ways.
#
# --dock-test misaligned builds the shipped docking pair and yaws the probe 40 deg about
# its OWN PORT, so its axis leaves the kDockAlign cone (5 deg since #1152). The pair also
# sits at a 0.78 m face gap, which is well outside this r1 pair's 0.10 m capture distance,
# so two gates could answer and the panel picks the axis: the gate asks the axis question
# before the distance one, and this is what pins that order from the other side of 1026-b,
# where a rails state outranks the same geometry.
# 40 deg rather than the 6 that would clear the cone: the angle is the fixture's, the cone
# is the game's, and a margin here means a retune of the cone cannot quietly turn this case
# into one that measures nothing. Since #1152 fixed the fixture's authored velocity the pair
# does not wander at all: every one of the six rows a 3 s run prints reads align=37.4 with
# the faces at 0.78 m, so the verdict is not a race against drift.
# This is the state where a player is doing everything they can see -- closing on a port
# they line up by eye -- and nothing tells them the answer is rotation. The panel is the
# approach dial for a pair like this, and at this fixture both of its markers sit pinned on
# the rim; the line it emits at 2 Hz prints `why=misaligned` with the angles behind that,
# which is what this case reads. The unit tests in tests/test_dock.cpp pin the cone
# boundary itself from the constant.
#
# The refusal is the point, so it is FORBIDden as well: the mate must really not happen.
# A window that names a gate while the hulls dock anyway is a window lying.
#
# at=/size= is the anchor pin, as in 972: this window hangs below the Resources window
# (uiwins.cpp), and ui::Manager lets a lost anchor stand -- the panel just moves to the
# middle of the view, which no widget list shows. The size is the window's declared
# initial_size rather than whatever the widest line happened to measure, so both this case
# and 1026-b pin the same rect, and it only moves when someone changes uiwins.cpp or the
# Resources bar above it on purpose. That rect is also what sizes the approach dial
# (dockDialRadius, gameui.cpp) -- the ring takes whatever square the window has -- so the
# pin doubles as "the instrument is the size the panel declares, not a collapsed one".
# cap= IS THE GATE (#1152). Every other case that cares about the capture distance asks the
# law in C++ or reads only a verdict here; this is the row where the pair's own distance
# reaches an e2e case as a figure, so it is where the dial's capture ring gets pinned to the
# gate it draws. The fixture's ports are r1s -- 0.25 m deep, so 0.4 of the shallower one is
# 0.10 m -- and the faces sit 0.78 m away, seven capture distances short, which is why the
# panel has two candidate gates and still names the axis.
# The `is not None` half is not decoration: DOCKWIN_RE's figure block is optional (a
# why-only row has no line to plot), so a measurable row that lost a column parses as a
# short row and keeps matching. Without it this case could print the word and lose every
# number.
CHECK len(dockwin) >= 3
CHECK all(r["cap"] is not None and abs(r["cap"] - 0.10) < 0.005 for r in dockwin)
CHECK all(r["gap"] is not None and r["gap"] > 5.0 * r["cap"] for r in dockwin)
CHECK all(r["why"] == "misaligned" for r in dockwin)
NAME docking-window-says-why-a-dock-refuses
CLAIM The Docking panel reports the gate that stopped a mate, and the pair it calls refused really does not mate.
KIND invariant
ARGS --dock-test misaligned --width 1280 --height 720 --timeout 3
ARGS --ui-click 200,"Windows/Docking"
EXPECT Dock-test (misaligned)
EXPECT [dockwin] a="dockprobe" b="dockstation" why=misaligned
EXPECT at=821,144 size=451,470
FORBID [dock] t=
# The GO verdict (#1039) is handed over by the gate when hulls actually mate, so a pair
# this panel calls refused must never produce one -- not now, and not from a latch that
# outlived the moment it describes.
FORBID why=go
FORBID FAILED
