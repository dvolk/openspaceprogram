# #452: this case claimed the glider's AoA "swings toward the trimmed angle and
# settles" while every CHECK it had only proved the swing is BIG. It does not
# settle, and pretending otherwise hid the actual finding, so the CLAIM now says
# what happens and the checks pin it. Measured on this build (glider, Duna pad,
# R then T then W, --drag-log; the log samples on wall-clock, so the exact rows
# drift a little run to run -- pin the order, not the seconds):
#
#   t=5.9  AoA   0.6   |L|    104 N |tau|    69 Nm  CLa  95.99  Ind  0.02  Profile   0.72  SM +0.64
#   t=6.9  AoA   9.8   |L|   1243 N |tau|   861 Nm  CLa  94.53  Ind  4.23  Profile   1.45  SM +0.64
#   t=7.9  AoA  25.6   |L|   1813 N |tau|  1484 Nm  CLa -59.98  Ind 13.55  Profile   5.23  SM +0.64  <-- inside the droop
#   t=9.0  AoA  42.1   |L|      0 N |tau|   499 Nm  CLa   0.00  Ind  0.00  Profile  11.33  SM -      <-- past 2x stall
#   t=10.0 AoA  55.8   |L|      0 N |tau|   691 Nm  CLa   0.00  Ind  0.00  Profile  16.76  SM -
#
# Three things happen in that order and all three are pinned here:
#  1. the swing GROWS. Every sample is further off the flow than the one before
#     it, so the wheels are losing: |tau| peaks at 1484 N m against the shipped
#     wheel's budget, which is #399/#403's whole complaint, not a settling
#     airframe;
#  2. CLa turns NEGATIVE at AoA 25.6, inside the droop between stall_angle (20.1
#     deg) and twice it -- #487's band, where a rotating surface feeds its own
#     swing instead of damping it;
#  3. by AoA 42.1 the wings are past 2x stall_angle, where liftCurve is
#     identically zero: lift is exactly 0.00 N, CLa 0.00, Induced 0.00 and SM
#     DASHES because there is no slope to divide by. The airframe has stopped
#     being a wing. The Induced row is #462's pairing, which #504 asked to get
#     back: since #503 capped a full-lock surface at its deflection stall, the
#     shipped planes never reach a zero-lift attitude in any case, so nothing
#     printed one. This does, and it prints Induced=0.000 with it.
# Re-baseline this case when the attitude work lands (#425's allocator, #482's
# yaw, #487's droop) -- a settling airframe should FAIL it, deliberately.
NAME glider-aoa-swing
CLAIM A glider held nose-up runs its angle of attack away through the stall band instead of settling: the swing grows every sample, the lift slope turns against the airframe inside the droop, and past twice the stall angle the wings make no lift at all.
KIND invariant
ARGS --time-accel 1 --startship glider,res/ships/glider.json,Duna,pad
ARGS --timeout 10 --drag-log
ARGS --sim-press 1000,2000,R
ARGS --sim-press 1500,3000,T
ARGS --sim-press 5500,2500,W
EXPECT [drag]
CHECK len(drag) >= 2
CHECK any(d["F"] > 0 and d["rho"] > 0 for d in drag)
CHECK max(abs(d.get("aoa", 0.0)) for d in drag) > 30
# Only over rows where air actually pushed: the pad row prints A=0.00, and a
# comparison against zero is satisfied by any shape at all (the same trap the
# Profile check below documents).
CHECK (lambda ds: (ds and max(d["a"] for d in ds) > min(d["a"] for d in ds) * 1.05))([d for d in drag if d.get("aoa") is not None and d.get("a") is not None and d["F"] > 0.0])
# WHAT USED TO BE THE Cd SPREAD, and where the shape story went. The area-weighted
# Cd mean used to move 0.78 -> 0.66 -> 0.82 across this swing, because the wings
# (cd 0.2 nose-on then) entered and left the area weighting as their planforms came
# into the wind. #455 took the lifting and steering parts out of that mean entirely,
# so Cd= is now the BODY's mix and it barely moves: 0.838 nose-on, 0.859 at 55.8 deg
# -- 2.5%, from the pod and fins presenting more of themselves as the airframe turns.
# The old CHECK (a 5% spread on Cd) stopped being a pin and became an accident, so it
# is gone. What grows across the same swing instead is the surfaces' own bill:
# Profile= goes 0.72 -> 16.76 m2 of CdA, a 23x climb, because the planforms turn to
# the wind and the cd blend walks from the authored 0.03 toward the 1.0 side value.
# That is the airframe's shape in the log -- it just no longer pretends a wing is a
# blunt body. Filter matters: the pad row prints a Profile off a zero flow direction
# (12.16 m2 with |F| = 0), the same trap the A check above documents.
CHECK (lambda ds: (ds and max(d["profile"] for d in ds) > min(d["profile"] for d in ds) * 8.0))([d for d in drag if d.get("profile") is not None and d.get("aoa") is not None and d["F"] > 0.0])
# The body's Cd mean stays inside the mix the parts catalogue implies -- pod 0.35
# forward, tank and engine ~1.0, area-weighted to 0.84 nose-on and 0.86 broadside.
# Nothing here should move much, and if it starts to, a part's silhouette is being
# counted that should not be in the union at all.
CHECK all(0.75 < d["cd"] < 0.95 for d in drag if d.get("cd") is not None and d["F"] > 0.0)
# --- #452: what the swing actually does, in the three steps the header table
# measures. The samples are wall-clock gated, so count rows rather than matching
# them to seconds.
# (1) no settling: over the rows where the stick was held, |AoA| never comes back
# down by more than a few degrees -- each sample is at least as far off the flow
# as the one before, all the way to the widest.
CHECK (lambda ds: (len(ds) >= 3 and all(b["aoa"] >= a["aoa"] - 1.0 for a, b in zip(ds, ds[1:])) and ds[-1]["aoa"] - ds[0]["aoa"] > 20))([d for d in drag if d.get("aoa") is not None and d["aoa"] > 0.0])
# (2) inside the droop the slope reverses: CLa goes negative while the airframe
# is still making lift (the stall band, not past it).
CHECK any(d.get("cla") is not None and d["cla"] < 0.0 and d.get("L", 0.0) > 100.0 for d in drag)
# (3) past twice the stall angle (0.35 rad x 2 = 40.1 deg) the curve is
# identically zero, so lift AND slope are exactly zero and the margin dashes --
# and the induced term that is billed off that lift goes to zero with it, which
# is #462's pairing and the row #504 said the suite had stopped printing.
CHECK any(d.get("aoa") is not None and abs(d["aoa"]) > 41.0 and d.get("L") == 0.0 and d.get("cla") == 0.0 and d.get("induced") == 0.0 and d.get("sm") is None for d in drag)
