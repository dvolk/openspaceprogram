# Ship RCS fuel: a ship on an inertial orbit holds N (RcsForward) until its
# hydrazine mono runs out. RCS is a fixed thrust gated on the ship's
# propellant (consume-then-arm, like the ship's engines), so the burn both
# changes the velocity AND sheds the fuel mass -- and STOPS when the 40 kg is
# spent (key-down-but-empty in the tail of the hold).
#
# The run is at 10x so the ~43 s of sim-time burnout lands at ~4.3 s of wall
# time; N is held 1.0 s..15.0 s (wall), past the burnout, so the tail of the
# hold is key-down-but-empty (no thrust). The hydrazine must fall from the
# full 40 kg to ~0 (the propellant is gone), and the orbit energy must have
# changed (the RCS actually thrust).
NAME ship-rcs-fuel
ARGS --ship res/ships/rcs_test.json --scenario inertial-orbit --time-accel 10 --timeout 18 --fuel-log --orbit-log --orbit-interval 0.5 --sim-press 1000,14000,N --frame-cap 30
EXPECT Building ship 'rcs_test' (2 parts)
FORBID GL_
FORBID error:
CHECK len(fuel) >= 3
# the hydrazine pool (the single fuel group, g0) starts full (40 kg)...
CHECK first(fuel)["groups"][0]["N2H4"][0] > 30.0
CHECK first(fuel)["groups"][0]["N2H4"][1] > 35.0
# ...and ends nearly empty (the 40 kg is spent)
CHECK last(fuel)["groups"][0]["N2H4"][0] < 1.0
# the burn actually thrust (E is direction-independent; a single velocity
# component would depend on the RCS direction vs the orbit)
