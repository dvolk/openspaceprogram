# The orbital-plane overlay used to refuse any ship whose conic meets the body,
# which is every ship flying in an atmosphere: the rings vanished, and with them
# any sign that the Map plane combo does anything -- exactly when a plane change
# is on the table. It now refuses only a ship actually resting on the ground
# (case 206), where h_hat is the circle the ground draws under the ship rather
# than an orbit.
#
# Flying is also where the marker bug bit hardest: at these speeds the ground's
# own motion is a large share of the velocity, so the old prograde icon pointed
# away from the orbit's prograde by an amount that grows as the ship slows.
NAME plane-overlay-while-flying
ARGS --timeout 8 --time-accel 1 --startship racer,res/ships/racer.json,Kerbin,flying-low
ARGS --plane-log --orbit-log --orbit-interval 2
EXPECT [planelog]
FORBID FAILED
FORBID GL_
FORBID error:
CHECK len(plane) >= 2
CHECK all(p["frame"] == "rot" for p in plane)
# The state the old gate refused: a suborbital arc, periapsis deep under the
# surface. Assert the premise so the case cannot drift into a real orbit and
# stop testing anything.
CHECK all(o["peri"] < 600000 for o in orbit)
# A suborbital arc still has a plane, and the markers still sit in it.
CHECK all(abs(sum(a*b for a,b in zip(p["prg"], p["n_orb"]))) < 1e-5 for p in plane)
CHECK all(abs(sum(a*b for a,b in zip(p["nrm"], p["n_orb"]))) > 0.99999 for p in plane)
# Kerbin's obliquity, measured in the Equatorial slot: the overlay is drawing a
# reference plane here, not just the orbit's own ring.
CHECK all(p["plane"] == "equ" for p in plane)
CHECK all(p["ticks"] == "drawn" for p in plane)
CHECK all(p["inc"] > 15.0 for p in plane)
