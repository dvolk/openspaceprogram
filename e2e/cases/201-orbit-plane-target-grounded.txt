# A GROUNDED vessel target has no orbit about the focus: the "conic" it traces
# there is the circle the ground draws under it, i.e. the body's own equator
# plane wearing the target's name. targetPlaneNormal refuses it, so the slot
# falls back to the ecliptic and labels itself ecl, and --map-dump drops the tgt
# row rather than printing that fallback under a "tgt" name.
#
# The transfer planner still accepts the same target -- the gate is about planes,
# not about reachability -- so [xferlog] must still name it. Without the gate,
# "Target orbit" would quietly become "Equatorial" for every player who targets a
# landed vessel, which is most of them.
NAME orbit-plane-target-grounded
ARGS --time-accel 1 --timeout 6 --startships e2e/fixtures/startships.json
ARGS --transfer-target tanker --map-plane 3
ARGS --orbit-log --orbit-interval 1 --map-dump 4000 --xfer-log
EXPECT [mapdump]
EXPECT [xferlog]
FORBID FAILED
FORBID GL_
FORBID error:
FORBID slot=tgt
CHECK len(mapb) == 3
CHECK all(x["target"] == "tanker" for x in xfer)
CHECK all(o["plane"] == "ecl" for o in orbit if o["t"] > 1.0)
