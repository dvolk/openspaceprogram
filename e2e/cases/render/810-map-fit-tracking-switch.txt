# The Tracking map pairs a BODY with the conic in g.hud.view, and that snapshot belongs
# to the hull the state pass saw -- not the hull the Tracking Ship List just selected.
# drawTrackingMap re-takes it (syncShipView) so the pairing cannot straddle two vessels
# no matter what order trackingDrawUi draws its windows in (#810).
#
# Only the Mun row is pinned, and that is deliberate. Entering the Tracking Station
# re-fits NOTHING: the fit latch (g.map.fit_body/fit_ship) is shared with the flight
# map, and the Kerbin row this run already printed at boot satisfies it. A Kerbin CHECK
# here would be the FLIGHT map's assertion wearing this case's name. Anchoring on the
# tracking push is what makes the row belong to this window.
#
# Teeth (both mutations run by hand, neither shipped): swap the two trackingDrawUi
# statements with the guard left IN -> still PASS, the order has stopped mattering.
# Same swap AND delete the syncShipView call -> exit -6 on fitMapView's assert
#   Assertion `!ship || ship->m_parent == &body' failed
# and the Mun fit never prints. The shipped order hides that hazard: the map draws
# first, so a stale snapshot only ever lasts one frame. ("Assertion" is already in
# run.py's DEFAULT_FORBID, so it needs no line here.)
#
# 325000 m is the Mun's 200 km radius plus 1.25 x its 100 km shell floor -- case 352's
# own figure for the same bed -- and the "-> 3250.0 m/px" tail is IDENTICAL in the two
# windows, because fitMapView's scale comes from kMapFitRadiusPx (100 px), not from the
# window: the edge-to-edge Tracking canvas decides how much of the fit is visible, not
# what a pixel is worth.
NAME map-fit-tracking-switch
CLAIM The Tracking Station map fits the newly selected hull's body and orbit.
KIND invariant
ARGS --timeout 6 --time-accel 1 --startship racer,res/ships/racer.json,Kerbin,inertial-orbit
ARGS --startship probe,res/ships/racer.json,Mun,inertial-orbit
ARGS --sim-press 1000,0,ESCAPE
ARGS --ui-click 2000,"Game Menu/Tracking Station"
ARGS --ui-click 3000,"Tracking Ship List/probe"
EXPECT Active ship 2 of 2: probe
CHECK re.search(r"spacecenter -> tracking \(push\).*?\[mapfit\] Mun: body 200000 m, fit 325000 m -> 3250\.0 m/px", out, re.S)
CHECK len(re.findall(r"\[mapfit\] Mun:", out)) == 1
FORBID FAILED
