# An escaping ship has no apoapsis (-1 in the elements), so the fit falls back
# to the radius it is at now. That is self-consistent with the open arc, which
# the map already truncates at the view edge rather than at a fixed distance.
#
# The escape bed sits at 0.85 x shellEdge, so #682 lifting Kerbin's shell off the
# 100 km floor to 1.2 x 85 km = 102 km moves this row too: 600000 + 0.85 x 102000 =
# 686700 m. It is the same authoring change seen from a second bed -- 352 reads the
# 1.25 one.
NAME map-fit-open-conic
CLAIM An escaping ship's map opens framed on its current radius.
KIND invariant
ARGS --timeout 4 --startship racer,res/ships/racer.json,Kerbin,escape
FORBID error:
CHECK re.search(r"\[mapfit\] Kerbin: body 600000 m, fit 686700 m -> 6867\.0 m/px", out)
