# The Venus cloud platform rides the wind, so it has no orbit to draw (#872): the map
# gives it a marker and a name and deliberately NO conic -- an ellipse would promise a
# path the player could fly, and a balloon platform has none.
#
# A hull parked on the platform makes Venus the map's focus, which is the view where the
# platform is the thing worth finding. The Surface Map has always refused this site --
# its lat/lon anchor goes stale within the hour -- so before this feature the platform
# was on no map at all.
NAME air-platform-mark-has-no-conic
CLAIM The map marks a wind-riding platform as a point: marker, name, no orbit line.
KIND invariant
ARGS --system res/systems/solar_system.json --time-accel 1 --timeout 6
ARGS --map-dump 2500 --dbg-log --orbit-interval 1.0
ARGS --startship skiff,res/ships/skiff_gear.json,Venus,pad,site=venus_cloud_platform
FORBID error:
CHECK len([m for m in mapbldg if m["id"] == "venus_cloud_platform"]) == 1
CHECK all(m["kind"] == "air" and m["focus"] == "Venus" for m in mapbldg if m["id"] == "venus_cloud_platform")
# The point of the feature: pts=0 is not a missing sample, it is no conic -- and conic_r
# agrees, so the two cannot disagree about what the window drew.
CHECK all(m["pts"] == 0 and m["conic_r"] == 0.0 for m in mapbldg if m["id"] == "venus_cloud_platform")
# No placement anchor either: an air platform's pose comes from the wind law, so the row
# prints "none" instead of an epoch state the building never uses.
CHECK all(m["anchor"] is None for m in mapbldg if m["id"] == "venus_cloud_platform")
# A map WINDOW marked it this frame (Game::map.station_marks) rather than the dump
# inventing a mark no window draws.
CHECK all(m["drawn"] >= 1 for m in mapbldg if m["id"] == "venus_cloud_platform")
# The mark sits at the platform's live pose: the same radius tickPose drives, at the
# cloud-deck altitude it drifts along.
CHECK len(bldg) >= 1
CHECK all(any(b["id"] == m["id"] and abs(b["r"] - m["r"]) < 1.0 for b in bldg) for m in mapbldg if m["id"] == "venus_cloud_platform")
