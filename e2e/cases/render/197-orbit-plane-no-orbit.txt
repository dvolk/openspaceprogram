# The overlay's grounded gate. A ship on the pad still has an h_hat -- it is
# co-rotating with the ground -- so without a gate the overlay draws a cyan ring,
# a yellow ring and two node ticks for a plane that belongs to nothing, and calls
# the node "where a plane change is cheapest". The gate is now grounded-vs-flying
# rather than periapsis-vs-surface, because a FLYING ship's suborbital arc does
# have a plane worth drawing (case 205); this case pins that the pad still gets
# nothing.
#
# --plane-log draws the overlay itself, so the absence of [planelog] here is the
# gate and nothing else. The checkbox is clicked anyway: a click that misses its
# widget prints FAILED, which the next line forbids.
#
# The second half is the same ship's prograde. A landed ship has no plane to
# draw, but it does have an orbital velocity -- the ground's own motion -- so the
# ORBITAL window's Prg/Rtg must be a number. They used to normalize the ship's
# own velocity, which on the pad is a zero vector, and printed nan beside Inc.
NAME orbit-plane-no-orbit
CLAIM A grounded ship gets no plane overlay.
KIND invariant
ARGS --time-accel 1 --timeout 6 --startship racer,res/ships/racer.json,Kerbin,pad
ARGS --plane-log --info-log --orbit-interval 1
ARGS --sim-press 1500,0,ESCAPE
ARGS --ui-click 2500,"Game Menu/Settings"
ARGS --ui-click 3500,"Settings/Orbital plane"
EXPECT [orbinfo]
FORBID [planelog]
FORBID prg=nan
FORBID rtg=nan
FORBID FAILED
FORBID error:
CHECK len(plane) == 0
