# The Surface Map marks every VAB_LAUNCH_PAD on the mapped body: an amber
# triangle at equirectLonLat(pad->dir), named either beside it ("Site labels")
# or on hover. The projection is exact -- StaticBuilding::dir is a unit up in
# the body's ROTATING frame, the same frame the map's pixels are baked in --
# and tests/test_buildings pins that round-trip against each site's authored
# lat/lon. What is pinned HERE is the count, because the marker filter is a
# flag string: a typo draws no sites at all and still compiles clean.
#
# Earth, not the default Kerbin system, because it carries the shipped real
# site table (14 sites + the pole pad) and so is the case where the markers
# actually have to coexist. Opening the window is what puts the overlay on
# screen at all -- M computes the map even with the window shut -- and the
# two clicks on "Site labels" walk the checkbox both ways.
NAME surfmap-launch-sites
CLAIM The Surface Map marks every launch pad on the mapped body.
KIND golden
ARGS --system res/systems/solar_system.json --startship racer,res/ships/racer.json,Earth,pad
ARGS --timeout 12 --surfmap-log --surfmap-n 128
ARGS --ui-click 2000,"Windows/Surface Map"
ARGS --sim-press 3000,0,M
ARGS --ui-click 4000,"Surface Map/Site labels"
ARGS --ui-click 5000,"Surface Map/Site labels"
EXPECT [surfmap]
CHECK len(surfmap) >= 2
CHECK last(surfmap)["body"] == "Earth"
CHECK last(surfmap)["sites"] == 15
FORBID error:
FORBID FAILED
