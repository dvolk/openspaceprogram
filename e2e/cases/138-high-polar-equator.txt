# The high-polar bed must be polar about the body's SPIN axis, not its rail
# normal (#174), and the readout measures inc against the focus's EQUATOR
# (#171). Kerbin's 23.44 deg axial tilt is what separates the two: a bed built
# about the spin axis reads exactly 90.0000, one built about the rail normal
# reads 23.44 (see 171-plane-readout). Before #171 this bed read 85.8938 --
# inc was measured from the parent's +Z, so the number carried the parent's
# node rather than the bed's polar-ness, and the same bed reported 89.6405 on
# Mun, 52.2238 on Duna and 16.5832 on Minmus.
NAME high-polar-equator
ARGS --time-accel 1 --timeout 6 --orbit-log --orbit-interval 1 --startship racer,res/ships/racer.json,Kerbin,high-polar
FORBID GL_
FORBID error:
CHECK len(orbit) > 3
CHECK all(abs(o["inc"] - 90.0) < 0.01 for o in orbit if o["t"] > 1.0)
CHECK all(o["ecc"] < 0.01 and o["peri"] > 700000.0 for o in orbit if o["t"] > 1.0)
