# --vab-scenario bogus used to survive boot and abort at LAUNCH with an
# uncaught throw from scenario_by_name -- "terminate called" + SIGABRT, a core
# dump in the middle of the loop (#16). The scenario list is short and fixed, so
# name it at boot instead; the message is scenario_by_name's own and already
# lists the valid names.
# This guards the PARSER, not the game: the top-bar scenario dropdown only offers
# real beds, so a bad name can only arrive through this flag. Launch cases pick
# the row instead (57).
NAME vab-bad-scenario
ARGS --timeout 4 --vab res/ships/racer.json --vab-scenario bogus --ui-click 2000,"VAB TopBar/LAUNCH"
EXPECT error: --vab-scenario: unknown scenario 'bogus'
EXIT 1
FORBID terminate called
FORBID [vab] launched
FORBID GL_
LIMIT 60
