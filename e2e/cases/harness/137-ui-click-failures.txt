# --ui-click must fail loudly, not click something else. Two of the ways a
# path is wrong: no such widget, and a label that several widgets share. Pins
# that the failure is reported rather than resolved to an arbitrary match -- the
# whole point of naming widgets instead of aiming at pixels.
#
# The ambiguous half used to be demonstrated by the Controls window, whose 63
# rebind buttons were all labelled "rebind" (#165). #165 is fixed now -- every
# row is "rebind##<slotName>" -- and no shipped window carries two identical
# CLICKABLE labels any more. Re-measured after #1148 added a slot (1920x1080, this
# case's own sequence, dump at 4.0s): the key map holds 66 slots, and 38 of them
# fit on screen -- 37 `rebind##` rows plus one `press a key...##warp_up`, because
# this case clicked that row into capture mode, plus 38 `clear##` rows. No label
# repeats among the clickable rows. (The totals are left out on purpose: which
# rows are drawn depends on when the dump lands, and the Title Menu's own rows
# include a version string that changes every commit -- a CHECK on a count here
# would be a flake factory.) The key column's 66 readout rows DO repeat ("W"
# three times, once per movement group, 28 of the whole set tagged clipped as the
# window runs below the display -- #1150), but a readout row is never a match
# target: findMatches() skips it.text, which is what #601's marker is for. So the
# case pins only the not-found shape and the MISMATCH guard. findMatches()'s
# "ambiguous (N matches)" branch is live code with nothing left in the shipped UI
# to exercise it; a synthetic duplicate would be the only way to pin it.
NAME ui-click-failures
CLAIM A bad --ui-click path fails loudly as not-found, never as a stray click.
KIND harness
ARGS --timeout 6 --ui-click 1500,"Title Menu/Controls" --ui-click 2500,"Controls/rebind##warp_up" --ui-click 3000,"Title Menu/No Such Button"
# The positive control #165 bought: one row of the 66 slots, named by its slot, so
# the same run that shows a bad path failing also shows a good qualified path landing.
EXPECT path="Controls/rebind##warp_up"
EXPECT path="Title Menu/No Such Button" FAILED not found
FORBID FAILED MISMATCH
FORBID error:
