# The recorder computes nothing: a row is the reading the physics already published
# for the tick it was sampled in, in the flight logs' own grammar (#665's one-seam
# law, applied to the trace). That is the whole claim, so this case never trusts the
# file on its own -- it checks the trace row for row against what --drag-log printed
# at the same instants, and pins the cadence that puts four samples between each pair
# of logged ones (--record-interval 0.25 against --orbit-interval 1).
NAME record-trace-agrees-with-the-log
CLAIM --record writes a trace whose rows are the readings --drag-log printed at the same ticks plus the numbers the SURFACE and ORBITAL windows show, and four of them land per log row.
KIND invariant
ARGS --time-accel 1 --width 1920 --height 1080 --startship skiff,res/ships/skiff.json,Kerbin,flying-cruise
# --no-paint: this case reads logs and a file, never the window (#666).
ARGS --sim-steps 900 --drag-log --record --record-interval 0.25 --no-paint
ARGS --sim-press 500,3000,R
ARGS --sim-press 500,20000,T
# The Recorder window opens HELD (#972): its Plot waits for Start, and the ring --
# the buffer that window draws -- only fills while unheld. --no-paint keeps the imgui
# pass alive (main.cpp: only the 3D half goes away), so --ui-click reaches the window
# here exactly as painted. Without these two clicks this case was red at HEAD BEFORE
# #947 touched anything: ring=0, because it never pressed Start.
ARGS --ui-click 2000,"Windows/Recorder"
ARGS --ui-click 3000,"Recorder/Start"
EXPECT record:
EXPECT (one row per 250 ms)
EXPECT 60 rows
# ring= is the other sink (#972): the history buffer a Recorder window would draw.
# Same gate, one sampler, no load in this run -- the counts are the same number only
# while nothing is held. Start lands at 3 s of this 15 s run, so the ring takes the
# samples from 3.0 s (the Start click is processed before that grid slot's sampler
# runs; #972's Pause at 8000 excluding its own slot shows the same ordering) through
# the last grid slot at 14.75 s: 48 of the trace's 60. The file keeps all 60 because
# a held plot must not throw evidence away -- that asymmetry IS the #972 design, and
# pinning 48 beside 60 is where the game says so.
EXPECT ring=48 ->
# The cadence: --orbit-interval gates [drag] at 1 s, --record-interval the trace at
# 0.25 s, both on the same scripted clock and both armed at tick 0.
CHECK len(drag) >= 10
CHECK len(rec) == 4 * len(drag)
# Row for row: the drag row at tick 60(n+1) is the trace row at tick 15(4n+4), so
# rec[3::4] is the trace's copy of the [drag] list. The names differ where the
# parsers renamed them ([drag]'s cd/a/induced/airT/airP/airA), and the trace's A= is
# the silhouette while its a= is the speed of sound, exactly as the [drag] line
# spells them.
CHECK all(d["alt_asl"] == r["alt_asl"] and d["rho"] == r["rho"] and d["v"] == r["v"] for d, r in zip(drag, rec[3::4]))
CHECK all(d["F"] == r["F"] and d["cd"] == r["Cd"] and d["a"] == r["A"] for d, r in zip(drag, rec[3::4]))
# L joins on purpose (#699): it is the channel on this line whose DEFINITION changed --
# the lift sum grew a control surface's deflection force -- and the two sides print the
# same lastLiftForce, the [drag] row at tick.cpp's printf and the trace at its recorder
# sample. Compared here, a future second spelling of the lift sum (one for the plot, one
# for the log) goes red instead of quietly disagreeing.
CHECK all(d["L"] == r["L"] for d, r in zip(drag, rec[3::4]))
CHECK all(d["aoa"] == r["aoa"] and d["beta"] == r["beta"] and d["cpl"] == r["cpl"] and d["induced"] == r["ind"] for d, r in zip(drag, rec[3::4]))
# #947's pair joins the row-for-row comparison for the same reason cpl and ind did: the
# [drag] row's SideCdA=/SideCp= and the trace's side=/sidecp= must be one reading, printed
# twice. Both sides print %.2f/%+.2f of the same double at the same tick, so == is exact.
CHECK all(d["sidecda"] == r["side"] and d["sidecp"] == r["sidecp"] for d, r in zip(drag, rec[3::4]))
CHECK all(d["airT"] == r["T"] and d["airP"] == r["p"] and d["airA"] == r["a"] and d["mach"] == r["mach"] for d, r in zip(drag, rec[3::4]))
# And the two clocks map onto each other: the trace's t= counts the run clock, which
# under --sim-steps is the same clock the [drag] rows' t= comes from -- less one
# interval, because the trace starts at its first sample rather than at tick 0.
CHECK all(abs(d["t"] - r["t"] - 0.25) < 1e-9 for d, r in zip(drag, rec[3::4]))
# The frame group (#674) is live even in a run that paints nothing: sc.refresh fills
# the snapshot the SURFACE and ORBITAL windows would show, and the trace reads that
# same snapshot rather than a second opinion. So the columns that need a body, a
# ground and a horizon are all numbers here, and the altitude pair differs only by
# how high the ground is (alt_asl is over the datum, alt_agl over the terrain).
CHECK all(r["alt_agl"] is not None and r["v_surf"] is not None and r["v_orb"] is not None and r["pitch"] is not None and r["hdg"] is not None and r["dv"] is not None for r in rec)
CHECK all(abs(r["alt_asl"] - r["alt_agl"]) < 2000.0 for r in rec)
CHECK all(-90.0 <= r["pitch"] <= 90.0 and 0.0 <= r["hdg"] < 360.0 and -90.0 <= r["lat"] <= 90.0 for r in rec)
# The v3 tail (#675) is live in a run that never leaves the ground for orbit: q is the
# hull's dynamic pressure in Kerbin's air, gamma the conic's flight-path angle the
# navball would quote, and the four burn totals whatever this hull has spent -- the
# case presses throttle, so the totals are readings rather than a row of dashes. What
# is pinned is their SHAPE, not their size: dv_exp and burns only ever grow (they are
# sums), q is positive where there is air, gamma stays inside a hemisphere, and the
# steering loss never exceeds the impulse it was taken out of.
CHECK all(r["q"] > 0.0 for r in rec)
CHECK all(abs(r["gamma"]) <= 90.0 for r in rec)
CHECK all(r["dv_exp"] >= r["steer"] and r["grav"] is not None and r["drag"] is not None for r in rec)
CHECK all(a["dv_exp"] <= b["dv_exp"] and a["burns"] <= b["burns"] for a, b in zip(rec, rec[1:]))
# seams= (v4, #972) is live here too. This run never docks, so every row says one
# free hull -- 0, which is a reading and not a gap. What is pinned is that the column
# carries the hull's count at all: a header channel the row forgets breaks the order
# check above, and a channel the sampler never fills reads 0 forever, which this case
# cannot tell from a genuine free hull -- so the non-zero half lives in the unit test's
# docked fixture instead.
CHECK all(r["seams"] == 0 for r in rec)
