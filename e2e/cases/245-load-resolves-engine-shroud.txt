# A Part's shroud is a def-derived render asset resolved at build time, like the
# chute canopy. Only the def-spawn path (vehicle.cpp) resolved it, so every LOADED
# engine silently lost the cylinder that hides what it shrouds -- invisible in the
# save file, and invisible until something draws it. The four mint sites are now
# one helper (issue #278) that resolves both, and the load reports each shroud the
# same way the spawn path does.
NAME load-resolves-engine-shroud
ARGS --load e2e/fixtures/save_racer --time-accel 1 --timeout 4
EXPECT Loaded game from e2e/fixtures/save_racer (active: racer)
EXPECT [shroud] engine_1: bare (meshes/engine_shroud.obj over meshes/engine.obj)
FORBID Assertion
FORBID Segmentation
FORBID GL_
FORBID error:
LIMIT 40
