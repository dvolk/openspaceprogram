# The pad-clear card (#231) answers on a LATER frame, so its callback must hold
# identity, not a pointer -- the invariant game.h states for every Question. It
# used to hold the pad's TerrainBody*, so a system switch that lands while the
# card is up frees the body and the answer dereferences it: bus error.
# --switch-system is the only way in: the modal scrim blocks the menu that would
# otherwise switch systems, but a hook fires regardless of it.
NAME vab-pad-card-survives-system-switch
ARGS --time-accel 1 --timeout 12
ARGS --vab res/ships/tanker.json --startship racer,res/ships/racer.json,Kerbin,pad
ARGS --startship probe,res/ships/tanker.json,Kerbin,high-orbit
ARGS --vab-launch 2000 --switch-system res/systems/solar_system.json --switch-at 2500
ARGS --ui-click 3000,"Question/Clear the pad"
EXPECT [vab] launch refused: 'racer' occupies 'main_space_port'
EXPECT [ask] racer is standing on Main space port. Clear the pad?  [Clear the pad | Cancel]
EXPECT [game] switched system -> res/systems/solar_system.json
EXPECT [ask] answered 0
# The pad's body is gone with the old system, so the answer refuses by name
# rather than reaching through a freed pointer.
EXPECT [toast] Clear the pad: Kerbin is not in this system
FORBID Cannot remove
FORBID [vab] launched
FORBID Segmentation
FORBID Assertion
FORBID GL_
FORBID error:
LIMIT 90
