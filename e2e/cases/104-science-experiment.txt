# Science v2: the headless "Run Experiment" hook records an observation on
# the active ship's first aboard crew (suit Part), then Recover Vessel scores
# it via the value model (base 10 x situation x body; a first-time high-orbit
# observation on the home body = 10 x 1.5 x 1.0 = 15). The [science] recorded
# / recovered lines are the e2e anchors. (Duplicate-refusal is unit-tested in
# test_science; the repeat/diminishing path is covered in science-recover-load.)
NAME science-experiment
ARGS --time-accel 1 --timeout 8 --startship racer,res/ships/racer.json,Kerbin,rot-orbit
ARGS --experiment 1500
ARGS --space-center 3000 --recover 4000 --recover-anywhere
EXPECT [science] t=
EXPECT recorded
EXPECT [science] recovered +15
EXPECT [recover] t=
EXPECT [spacecenter] entered
FORBID GL_
FORBID error:
