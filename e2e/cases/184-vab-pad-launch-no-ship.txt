# #235, the half 183 cannot reach. A PAD launch leaves the ship in the body's
# ROTATING frame at asl ~ 0, so the HUD is in surface mode and takes its AGL
# terrain sample on the launch frame itself -- the frame where the snapshot is
# still the one the state pass never filled (this VAB had no active vessel).
# That sample is what the ShipView::ship stamp exists to protect: drop the
# syncShipView call and this dies in Heightmap::sample's finiteness assert.
#
# 183 uses the inertial-orbit scenario, where surface_mode is false and the
# HUD never samples at all, so it pins the never-taken-snapshot readouts
# instead. Earth because only the heightmap bodies index memory on the way to
# a height: a procedural body returns NaN and limps on as -nan readouts.
# --vab-launch cannot catch either: that hook fires in vabUpdate, ahead of the
# state pass, so only the real button click lands on the stale frame.
NAME vab-pad-launch-no-ship
ARGS --system res/systems/solar_system.json --timeout 10
ARGS --vab res/ships/racer.json --info-log --orbit-interval 1
ARGS --ui-click 5000,"VAB TopBar/LAUNCH"
EXPECT [vab] launched 'racer' (4 parts)
EXPECT [scene] vab -> flight (enterFlight)
# On the deck, not orbit: a stale snapshot reads as zeros, which would put the
# ship at the body's centre (alt_agl ~ -6.4e6) rather than on the pad.
CHECK len(surf) >= 3
CHECK all(abs(s["alt_agl"]) < 1000.0 for s in surf)
CHECK all(s["sit"] == "landed" for s in surf)
