### 2.1 — containment edge, unused  (in progress)

Decisions (report left them open):

- Ownership: `contents` is NON-OWNING through phases 2-4, and the owner for
  inventory items is DEFERRED TO PHASE 5 (report step 2.1's second option).
  Rationale: an owning ~Part would double-free an aboard kerbal
  deterministically — ~Vehicle deletes crew (vehicle.cpp:1274-1276) BEFORE
  its parts (:1279). Documented in part.h where the fields live.
- The XOR invariant has a phase-2 exception: an aboard kerbal's part is BOTH
  attached (owner = its Kerbal vehicle shell) and contained (container = the
  capsule). The report's "never both" is the phase-5 end state. So the check
  is: every part's owner back-reference holds; a contained part's owner MUST
  be a character (isEva()); a capsule may only hold character parts; the
  container/contents back-references agree. Enforced via
  Vehicle::checkPartInvariants(), asserted from rebuildCompound (every
  build/stage/refresh) next to checkCompoundInvariants.
- checkPartInvariants RETURNS a bool (with a [part] diagnostic) instead of
  asserting itself: rebuildCompound asserts it (same hard-fail style as
  checkCompoundInvariants), and the headless test can call it directly and
  check the negative cases. assert() is uncatchable, which would make the
  "check actually fires" test impossible.
- `owner` is wired in the two attach primitives (setRoot/attach — covers
  build, load, docktest/radialtest and the hand-built test ships), then
  re-pointed in absorbShip (B's parts → survivor) and extractSubtreeAsShip
  (dropped side → new ship). A Part* is stable across both, so only the
  owner pointer moves.
- Test (tests/test_contain.cpp) uses a local `struct TestCrew : Vehicle`
  overriding isEva(), NOT the real Kerbal: eva.cpp includes game.h, which
  drags the whole game into a headless test link. The invariant is keyed on
  the isEva() virtual, so the stand-in exercises the same code path.

### 2.2 — aboardPart: index → pointer  (pending)

Decision: keep `aboardPart` as a `Part*` FIELD in this step (the report's
literal step), drop the `aboard` field (derived as `aboardPart->owner`),
delete crewRebase + both reindex maps + the dispatch. The containment edge
stays null until 2.4; the invariant still passes (nothing contained).
Save stays in the old int format for this commit (save.cpp maps the pointer
to an index on write and back on read); 2.3 swaps the format.
