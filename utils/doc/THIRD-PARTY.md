# Third-party code

Generated by utils/gen_third_party.py -- edit the script, not this file (--check fails when the file and the repo's pins disagree).

The release binary is linked static: `libSDL3.a`, `libSDL3_image.a`, `libSDL3_mixer.a`, `libGLEW.a`, `libassimp.a`, `libBulletDynamics.a`, `libBulletCollision.a`, `libLinearMath.a`, `libpng16.a`, `libz.a`, plus the header-only libraries compiled straight in. System libraries (`-lGL`, the X11 set) are dynamic and are not ours to ship.

Each row is what the repo actually pins, read from where that pin lives: the gitlink for a submodule, `bootstrap.sh` for the GLEW tarball, the version macro plus a file checksum for a vendored header. The licence name comes from the library's own text; `unknown` means a notice file exists and its shape is unrecognised -- read the path rather than guessing at a tag. `none found` means the library ships no notice file at all.

These arrive as one source file with no separate licence text, so the
notice is quoted here verbatim from the file the binary is built from --
MIT and BSD ask that it travel with the distribution in documentation,
and a 1 MB header nobody opens does not carry it.

## Conveying this

zlib, MIT, BSD and Apache-2.0 each require the copyright notice and the licence text to travel with a binary. This script copies every notice named above into `utils/doc/third-party/`, renamed for its library -- `glm-copying.txt`, not `copying.txt`, because eleven of these share two basenames and would overwrite each other in one directory. The release artifacts carry that directory: `make deb` installs it into `/usr/share/doc/openspaceprogram/third-party/` from `utils/third-party.install`, which this script also writes; the tarballs carry it as `doc/third-party/`, the AppImage as `usr/share/doc/third-party/`. The repo copy lives in `utils/doc/`.

Our own code is AGPL-3.0 and `res/` is CC-BY-SA-3.0, in `LICENSE.md`. That claim covers our work only: everything under `middleware/` keeps whatever its own library says it keeps.
